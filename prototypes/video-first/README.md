# 视频优先：可操作交互样稿

本地预览：[工作台](http://127.0.0.1:43719/lab.html) / [独立播放器](http://127.0.0.1:43719/index.html)。2026-10-23已由Codex启动本机服务；此地址仅在当前电脑及服务运行时有效。服务器仅监听127.0.0.1并只服务本目录，不连接Eagle或素材库。

需要恢复预览时，由Codex运行 `node prototypes/video-first/server.cjs`，不要求用户安装依赖或输入命令。开发检查 `node prototypes/video-first/check.cjs`；独立Chrome检查 `node prototypes/video-first/browser-check.cjs` 会生成有界证据且原三轮配额已用完，不能当日常检查反复运行。正式`plugin/`不依赖本目录。

## 如何体验

- 首次提示可立即关闭；右侧触边唤出标注/片段/记录/设置，无常驻按钮文字；Tab也能聚焦唤出。
- 点击画面播放/暂停，滚轮逐帧，按住左键左右定位/上下调速；右键短点观看时不执行，甩动或长按唤出轮盘。
- 记录打开继续播放，点击缩略图暂停跳转；一帧一卡，短信息在上方。关闭恢复原画面。进入标注后文字和圈画同在，视频几何不变。
- 画面右键短点或Enter保存；Shift+Enter换行，输入框保留原生右键和输入法。Esc退出有未存保护。圈画轮盘选择工具/颜色/橡皮/撤销，滚轮调粗细，Ctrl+Z撤销；画面文字直接原位输入。
- R进入片段，时间轴选择头尾；右键左右甩控制头尾，R/右键短点确认。未齐取消、同帧清除，Esc恢复旧范围。L切换循环，无范围提示两秒内消失。
- 设置靠右悬浮，打开暂停、关闭仍暂停，资源参数藏高级区；右上角可全屏，F11同入口。

工作台的六项参数、A/B、版本名、导入导出只在外壳，不是播放器产品控件。版本最多12个，仅包含参数/画面比例，保存在本机该站点的专用localStorage。更换预览端口会形成另一存储来源；导出JSON可移交版本。保存保护演示仅内存模拟，未写入Eagle。

## 真实程度与边界

画面为Canvas确定性合成示例，不使用AI图片、真实视频或播放器缓存。帧、播放和存储都由样稿模型演示，不能拿它验收真实定位、音画、高倍速、媒体准备、资源占用或长期稳定性。橡皮为命中对象擦除演示（整次拖动一步撤销），不是正式局部擦除算法；片段/R手势仅覆盖本轮必要路径，未复刻长按R全段浏览。全屏按钮已接浏览器API，但没有真实Eagle全屏通过证据。

“现状结构”页仅重现旧侧栏/底部控制占位，所有控件禁用；它不运行旧正式播放器。新样稿视觉尚待用户评价，不因自动检查通过就声称美观、好用或真实Eagle通过。
