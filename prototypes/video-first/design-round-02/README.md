# UI-02：扁平播放器静态稿

本目录与正式`plugin/`、上一轮可操作样稿隔离，只绘制页面状态。A深炭暖金采用连体工具轨，B青绿切角采用通高边轨与连续画幅，C钴蓝浮页用独立工具轨和离缝记录区；均有顶栏及最小化、最大化、关闭设计，不调用窗口API。

每款使用同一组源画幅、选中记录、片段范围与文字，分别截图观看、记录、标注、设置。四张源帧为`build-assets.cjs`确定性绘制的原创SVG，不是AI图片或真实素材。色彩和布局是候选，不是正式视觉规范。

图3按“按钮窄轨在左，记录四张单列纵排”实现；选中信息在顶部、缩略图只显示画面与圈画，编辑／删除属于选中记录。与前轮双列缩略图、浮层关系不明确相比，本轮明确了每个区的归属。设置与记录互斥是待验证提案；从记录进入编辑时继续保留原几何是既有要求，本轮四张静态状态只展示从默认观看进入标注，不冒充全部行为验收。

截图见`shots/a-board.png`、`shots/b-board.png`、`shots/c-board.png`，单状态另有同名前缀的PNG。浏览器`board.html?scheme=a`等只拼合这些截图，无可调工作台或真实操作。截图重现方法与有界证据见[捕获说明](CAPTURE.md)、[UI-02计划](../../../docs/experiments/UI02/plan.md)。

R/P精度、持久化保护、RAM额度和真实播放性能沿用正式项目，静态稿不承担这些验收。浏览器渲染通过和用户视觉认可分别报告。
