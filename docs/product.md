# 现行产品规范

本页按功能维护已批准行为；实际完成和待验只见[当前交接](progress.md)。需求R-01～R-08、性能P-01～P-04编号保留，不因整理改变门槛。历史阶段的“当前/下一步”不作为新授权。

## 当前产品定位与设计原则
从特效观察出发的视频参考与标注播放器，流畅拆解每一帧。优先服务特效师与学习者，对外不限定仅供特效师；辅助人观察、判断，不扩成素材管理、剪辑/合成制作或完整专业审片系统。
1. 保证观察连续、定位准确、操作直接。
2. 简洁来自合理组织，常用操作容易触达，低频能力按需收起，减少遮挡。
3. 各功能可独立使用或自然组合，不强制固定流程。
4. 优化兼顾准备时间、响应、画质和资源；不以功能数量或单项测试数字替代价值。
5. 明显改变使用习惯、输出或安全的未定细节先商定；长期愿景不自动授权开发、对外沟通或降低验收标准。

## 需求与当前行为
| 编号 | 现行要求 |
| --- | --- |
| R-01 素材与窗口 | Eagle选中单个本地视频后调用插件；复用已有窗口，再次调用才切源。库/素材/路径/源身份保持一致，中文及空格路径正常；换源旧回调不显示或写入旧数据。未选素材是正常空态，可“读取选中视频”；API/释放错误仍报错。 |
| R-02 播放与逐帧 | 首帧暂停待命；点击画面/空格播放暂停，编辑输入不抢空格，长按不重复切换。暂停立即停声/时钟，拖动和逐帧静音，释放后保持暂停。逐帧按实际源帧，不用平均帧率猜VFR；显示与声音按真实源时间同步。 |
| R-03 定位与观察 | 单一时间轴、最新目标优先、过期结果不覆盖。等待目标时保留上张确认帧，用frameHeld保护标注；最终定位/逐帧/标注必须准确。高倍速可跳过来不及显示的播放帧，暂停/循环/末帧身份不变。 |
| R-04 媒体准备与画质 | 默认720p，支持1080p/1440p/2160p有效尺寸，保持比例、不放大小源。代理模式先原片播放、后台完整H.264全I生成且核验后同帧接管；JPEG先整片准备。自动代理/提前解压固定开启，前台优先；没有旧稀疏补位、分段前台或代理条。 |
| R-05 文字与圈画 | 载入读取原生标注，点击准确定位；固定已确认帧后编辑，主动保存并独立读回才报成功。图形/文字按源帧绑定，草稿受关闭/切源保护；失败保留输入、未知结果先核查，不盲目重发。原生界面即时刷新不承诺。 |
| R-06 缓存与资源 | 完整有效缓存持久复用，身份/内容变化重验，临时任务取消后安全回收、不续旧源任务。缓存位于实际插件目录非C盘，不回退系统TEMP。默认RAM1GiB，可选512MiB、1～10GiB；JPEG压缩池≤总额1/8。代理独立额度默认5GiB、1～100GiB；JPEG5GiB。 |
| R-07 兼容与范围 | Windows/Eagle及已验格式分层承诺；2160p为UHD框，不保证DCI原尺寸/HDR/透明保真。取消旧30秒限制，仍保留120000源帧及索引/消息/资源边界。容器、编码和硬件偏好不能互相冒充支持证明。 |
| R-08 失败与数据安全 | 原视频保持不变，保存/删除仅按用户主动操作与既定保护。代理失败或容量不足可继续原片；先停写并回收本任务临时文件再报告安全终态。清理不删素材、标注、设置、活动/未知归属文件；未回收、未保存和结果未知不得显示成功。 |

## 操作与界面
- 视频优先、纯黑/低对比半透直角面板、淡蓝选中。左功能、右可调记录、图标轮盘、真实源帧刻度及片段循环；默认不额外显示帧/秒读数。侧栏展开、输入/退出、动画时保持视频及标注几何一致。
- 横拖按当前范围秒数一次计算pixelsPerFrame=clamp(2,8,240/秒数)，Ctrl速度1/4、Shift两倍，同时按普通速度；滚轮逐帧及源帧/循环边界保持。缓存热目标可闲时补邻域，冷目标可抢占，不承诺整段常驻RAM。
- 速度0.1×～4×，Z还原、X减速、C加速，步长按已保存设置；文字编辑保留原生快捷键，窗口/输入焦点不重复触发播放。上下素材切换仍暂缓。
- 片段选择与时间轴共享源帧草稿、确认/取消；有效循环过滤记录闭区间，关闭恢复全部。时间轴不出现整条聚焦蓝框，保留键盘/退出标注后的焦点恢复。
- 圈画含五种基础工具、文字、局部擦除、选择/调整、共享颜色及各工具属性记忆；编辑中Ctrl+Z撤销、Delete删除，无绘图重做按钮；文字输入按原生编辑。淡化前后各0～1秒，默认0.25，0仅本帧。
- 主动删除最后一条同帧原生文字同时清除该帧圈画；同帧仍有其它文字则保留共享圈画，外部库变化不擅自删圈画。未保存时保存后继续/放弃/返回，保存失败不得继续。
- 设置分级按需展开、中心随父项且边缘限位；外部首击仅关闭，不穿透播放。应用后保留位置并暂停；GPU加速默认开，统一解码/绘制/编码，明确软件回退且不偷偷降画质。RAM/草稿/旧偏好兼容与数据保护不变。
- 全屏由右上窗控/F11切换，顶栏按窗口/全屏规则隐藏；拖顶栏恢复窗口并保持抓取位置。小窗口关闭/保存可达，尊重减少动画。
精细操作的原批准条款按主题查[交互追溯](#按主题追溯)，不需要全文阅读全部历史。以上未重定义快捷键或改变原数据格式。

## 提示与错误反馈
- 普通完成结果、容量不足但已确认回收并继续原片、后台任务安全停止等可恢复通知，约2.2秒后自动渐隐。
- 同一结果的轮询更新不得重置寿命；新任务/新结果才重新计时。新普通通知出现时，旧普通通知立即渐隐。
- 进行中通知随真实任务结束撤下；保存失败、未保存、结果未知、清理未完成必须保留。
- 已知状态显式分类，不靠文案关键词判断。修改任意提示必须执行[计时回归](verification.md#提示计时与准备选择)，不能只看文本出现。

## 媒体与资源的专项约束
格式、UHD/竖屏/DCI尺寸、长JPEG选择、大代理确认阈值及120000帧解释仅在[能力表](releases/motionote-capabilities.md)维护，不在入口重复参数。
当前压缩音轨可无损复制到有界内存播放，不重编码、不写磁盘；未验证起点/编码或预算不足保守回原声，源变化/取消不能静默回退。非零等待、真实听觉同步及长片另验。
完整代理复用先核验；失败先确认进程退出和归属再回收。保护当前源各画质/活动读者与未知文件；JPEG闲置一天及容量淘汰沿既有规则。设置不提供删除当前源完整代理的权限。
实时监测默认关、独立窗口，只显示当前等待和四项资源；关闭停止采样。临时是代理子集，不重复相加；采样不是原子磁盘快照。旧用户体验记录、标准测试、report.html及待分析槽已退役，开发验证仍保留。

## 性能、可靠性与测量口径
| 编号 | 保留的目标和边界 |
| --- | --- |
| P-01 拖动更新 | 环境允许时接近60次/秒；统计实际有效画面提交，不用输入/请求数或无新目标重绘凑数。 |
| P-02 拖动响应 | 定位输入到目标画面提交P95≤50ms；取消/合并/取代、最长停顿及跟手体验同时报告，不冒充物理屏幕呈现。 |
| P-03 首次等待 | 原批准5～30秒样本首次总准备≤视频时长，不足5秒≤5秒；包括读取/分析/生成直到真正就绪。首次和复用单列；长片/新路径不得由旧样本外推。 |
| P-04 资源与稳定性 | 受管RAM/磁盘及在途预留受对应额度约束，连续操作不无界增长；进程/辅助进程峰值与采样范围另列，不等同缓存硬上限。代理可调额度是既有批准，不改写JPEG或历史实验配额。 |
以上是要求，不是已验声明；完整协议见[验证规范](verification.md#性能与证据口径)。不达标须说明并先解决或另行取得产品变更，不能静默降画质、精度或门槛。
