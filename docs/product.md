# 现行产品规范

本页按功能维护已批准行为；实际完成和待验只见[当前交接](progress.md)。需求R-01～R-08、性能P-01～P-04编号保留，不因整理改变门槛。历史阶段的“当前/下一步”不作为新授权。

## 当前产品定位与设计原则
从特效观察出发的视频参考与标注播放器，流畅拆解每一帧。优先服务特效师与学习者，对外不限定仅供特效师；辅助人观察、判断，不扩成素材管理、剪辑/合成制作或完整专业审片系统。
1. 保证观察连续、定位准确、操作直接。
   打开即显示准备状态，不在初始化工作开始前留下无反馈黑屏；续播接管定位后光标随播放前进，不能被已取代的拖动目标固定。
2. 简洁来自合理组织，常用操作容易触达，低频能力按需收起，减少遮挡。正式插件只呈现用户完成任务需要的操作、状态与必要决策；开发进度、能力/边界清单、实现术语、测试结论和验收说明在开发对话中向产品负责人说明，文档留档，不作为插件设置、说明面板或操作指引。开发预览的辅助控件不得进入正式插件。
3. 各功能可独立使用或自然组合，不强制固定流程。
4. 优化兼顾准备时间、响应、画质和资源；不以功能数量或单项测试数字替代价值。
5. 明显改变使用习惯、输出或安全的未定细节先商定；长期愿景不自动授权开发、对外沟通或降低验收标准。

## 需求与当前行为
| 编号 | 现行要求 |
| --- | --- |
| R-01 素材与窗口 | Eagle选中单个本地视频后调用插件；复用已有窗口，再次调用才切源。库/素材/路径/源身份保持一致，中文及空格路径正常；换源旧回调不显示或写入旧数据。未选素材是正常空态，可“读取选中视频”；API/释放错误仍报错。 |
| R-02 播放与逐帧 | 首帧暂停待命；点击画面/空格播放暂停，选定时间轴标注后焦点回时间轴、空格不再次点击标注。编辑输入不抢空格，长按不重复切换。暂停立即停声/时钟，拖动和逐帧静音，释放后保持暂停。逐帧按实际源帧，不用平均帧率猜VFR；显示与声音按真实源时间同步。 |
| R-03 定位与观察 | 单一时间轴、最新目标优先、过期结果不覆盖。等待目标时保留上张确认帧，用frameHeld保护标注；最终定位/逐帧/标注必须准确。高倍速可跳过来不及显示的播放帧，暂停/循环/末帧身份不变。 |
| R-04 媒体准备与画质 | 首次按屏幕选择1080p/1440p/2160p，已有偏好保留；细则见[能力表](releases/motionote-capabilities.md)。保持比例、不放大小源。代理模式先原片播放、后台完整H.264全I生成且核验后同帧接管；日常JPEG入口已撤下，旧偏好读入统一迁移到proxy；共用RAM/倍速等规则拆成小模块；旧JPEG前端不再加载或打包，旧源码仅供开发回归，旧缓存保护/清理仍保留。自动代理/提前解压固定开启，前台优先；没有旧稀疏补位、分段前台或代理条。 |
| R-05 文字与圈画 | 载入读取原生标注，点击准确定位；固定已确认帧后编辑，主动保存并独立读回才报成功。图形/文字按源帧绑定，草稿受关闭/切源保护；失败保留输入、未知结果先核查，不盲目重发。原生界面即时刷新不承诺。 |
| R-06 缓存与资源 | 完整有效缓存仅在本次运行内复用，身份/内容变化重验，临时任务取消后安全回收、不续旧源任务；跨次持久复用由退出清理替代。缓存位于实际插件目录非C盘，不回退系统TEMP。默认RAM1GiB，可选512MiB、1～10GiB；JPEG压缩池≤总额1/8。磁盘采用无额度选项、1 GB确认阈值，退出清全部可再生成的媒体缓存；具体实施契约见专项约束。物理预留、并发预留和异常恢复边界见能力表。 |
| R-07 兼容与范围 | Windows/Eagle及常用格式按实测承诺；新目标不追求覆盖Eagle全部扩展名、不要求用户选择JPEG兼容路线；2160p为UHD框，不保证DCI原尺寸/HDR/透明保真。取消旧30秒限制，仍保留120000源帧及索引/消息/资源边界。容器、编码和硬件偏好不能互相冒充支持证明。 |
| R-08 失败与数据安全 | 原视频保持不变，保存/删除仅按用户主动操作与既定保护。代理失败或容量不足可继续原片；先停写并回收本任务临时文件再报告安全终态。媒体缓存清理不删素材、标注、设置、活动/未知归属文件；永久删除素材后的圈画清理遵守下文数据归属规则；未回收、未保存和结果未知不得显示成功。 |

## 操作与界面
- 顶栏拖动使用统一指针路径；全屏恢复时保留本次拖动，跨屏坐标以宿主屏幕坐标为准，不混用显示器缩放。顶栏双击保留最大化/恢复，按钮不启动拖动；关闭撤销尚未完成的窗口移动。
- 设置精简：删除“能力与边界”和“代理磁盘额度”项目；删除整个操作提示面板、首次操作图示/自动引导、“重看操作提示”入口及旧快捷键说明面板，不以帮助页、折叠说明或空壳入口替代。此条替代历史首次引导/可重看要求。保留必要的任务进度、结果、错误和未保存/容量确认，不把删除教学指引误作取消数据保护。
- 视频优先、纯黑/低对比半透直角面板、淡蓝选中。左功能、右可调记录、图标轮盘、真实源帧刻度及片段循环；默认不额外显示帧/秒读数。侧栏展开、输入/退出、动画时保持视频及标注几何一致。
- 横拖按当前范围秒数一次计算pixelsPerFrame=clamp(2,8,240/秒数)，Ctrl速度1/4、Shift两倍，同时按普通速度；滚轮逐帧及源帧/循环边界保持。RAM命中直接显示，慢拖优先当前及前进方向附近帧，反向保留少量；快拖只保留最新待办，可显示沿方向追赶的有效中间帧，但光标保持用户目标，最终帧未就绪时禁止标注。无固定停手等待；重取帧/远跳优先当前目标。记录缩略图与附近帧轮换空闲机会，不承诺整段常驻RAM。松手后立即播放可接续尚在准备的原生目标，再按暂停可取消；不会以旧画面提前启动错误时间的声音。
- 速度0.1×～4×，Z还原、X减速、C加速，步长按已保存设置；文字编辑保留原生快捷键，窗口/输入焦点不重复触发播放。上下素材切换仍暂缓。
- 片段选择与时间轴共享源帧草稿、确认/取消；只显示“请拖动起点/终点”，结束第一段拖动后进入终点提示，不显示整段教学。有效循环过滤记录闭区间，拖动定位限制在头尾内；显式调整端点时恢复整段。端点用贴合时间轴的细括号，悬停/当前端点淡蓝，不包围整个按钮。时间轴不出现整条聚焦蓝框，保留键盘/退出标注后的焦点恢复。
- 时间轴拖动按最近实际源帧定位，光标和请求共用该帧，不先画原始鼠标位置再回跳；播放时钟仍按所在帧显示。标注保留准确位置，点击区最多左右各10px，按相邻点中线裁分；相邻间距不足12px或同帧多条时，点击展开简短列表，选定才跳转。单帧提示与密集选择均在帧点上方居中、边缘限位。列表保留键盘与外部关闭，只聚合展示，不合并数据。
- 圈画含五种基础工具、文字、局部擦除、选择/调整、共享颜色及各工具属性记忆；编辑中Ctrl+Z撤销、Delete删除，无绘图重做按钮；文字输入按原生编辑。淡化前后各0～1秒，默认0.25，0仅本帧。淡化时长输入框隐藏原生增减箭头；左键横拖每8px调整0.05秒，保留直接输入和键盘步进，Esc/取消/失焦撤回本次拖动，仍由“应用”保存。
- 主动删除最后一条同帧原生文字同时清除该帧圈画；同帧仍有其它文字则保留共享圈画，外部库变化不擅自删圈画。未保存时保存后继续/放弃/返回，保存失败不得继续。
- 设置分级按需展开、中心随父项且边缘限位；外部首击仅关闭，不穿透播放。说明延迟悬停时只显示简短用途，不介绍开发实现。N标注、R片段、B记录、O设置统一在按钮提示中展示；文字/输入法/重复按键/修饰键/草稿期间保护。圈画工具条未保存偏好时默认开，明确关闭仍保留。记录区编辑进入/退出使用140ms轻显隐，进入不动画布局，尊重减少动态效果。横拖仅显示当前箭头，不显示轮盘底色、文字或方向切换闪动。应用后保留位置并暂停；GPU加速默认开，统一解码/绘制/编码，明确软件回退且不偷偷降画质。RAM/草稿/旧偏好兼容与数据保护不变。
- 图标按钮的悬停/键盘聚焦提示统一小型半透深色直角材质、淡蓝灰文字，约400ms后出现；点击/移开/失焦即收起，不叠加系统原生title框。标注框退出使用140ms淡出和轻微下移；退出副本不接收输入、不延迟保存，重新打开或切源取消旧副本，遵守减少动画设置。
- 全屏由右上窗控/F11切换，顶栏按窗口/全屏规则隐藏；拖顶栏恢复窗口并保持抓取位置。小窗口关闭/保存可达，尊重减少动画。
- 新素材首次取得显示尺寸时，普通窗口按视频比例适配，另留顶栏和时间轴；使用当前显示器可用区域，最小窗口320×300。已最大化/全屏或等待期间用户改过窗口时不抢改；同源播放和画质更新不反复调整。画面不裁切、不拉伸，源片自带黑边及极端比例受可用屏幕/控件最小尺寸约束。手动拉伸即时跟随，几何过渡只用于主动开合记录栏。
精细操作的原批准条款按主题查[交互追溯](#按主题追溯)，不需要全文阅读全部历史；数据格式未改。

## 提示与错误反馈
- 不支持的文件格式使用居中说明：当前插件仅支持MP4、M4V、MOV、MKV、WebM；引导在Eagle重新选择视频，提供“读取选中视频”。不显示编码/源帧等实现术语，不与左下角红色错误和重试叠加；换源后撤下。其它加载、保存和清理失败仍按各自状态处理，不能误归类为格式不支持。
- 不再显示“圈画与文字已保存。”完成提示和进入圈画时的右键/长按/滚轮/Esc说明；必要的保存中、失败、未知结果、未保存及删除确认仍保留。此项为用户明确撤下的两条冗余文案，不代表隐藏全部错误或保护提示。
- 普通完成结果、容量不足但已确认回收并继续原片、后台任务安全停止等可恢复通知，约2.2秒后自动渐隐。
- 临时文件容量确认显示时，隐藏底下的次要代理进度小字；确认结束按当前任务状态恢复，不能因隐藏/显示重启旧提示寿命。保存/清理失败等必要错误不因此清除。
- 同一结果的轮询更新不得重置寿命；新任务/新结果才重新计时。新普通通知出现时，旧普通通知立即渐隐。
- 进行中通知随真实任务结束撤下；保存失败、未保存、结果未知、清理未完成必须保留。
- 已知状态显式分类，不靠文案关键词判断。修改任意提示必须执行[计时回归](verification.md#提示计时与准备选择)，不能只看文本出现。

## 圈画数据归属与删除
仅插件使用时，圈画和画面文字保存在插件目录的annotation-data；本机设置继续原位置，不迁入AppData，不增加圈画管理或导入导出面板。官方文字标注仍由Eagle管理。正常关闭保留永久圈画，临时媒体清理不得触碰它。
素材移入回收站保留圈画，恢复后可继续读取；永久删除后由插件维护清理对应圈画。插件运行时在打开/显示/获得焦点及每30秒分批检查，每批最多16个记录目录；插件未运行时下次打开再检查。当前正在使用的素材受保护，换源或重开后再清；不是即时删除承诺。仅在当前库可读、Eagle查询为空且对应素材文件夹连续两次确认不存在时清理；库离线、换库、查询异常、未知布局/文件、链接及并发保存保留数据。不同素材库不互相清理，不能因回收站素材被API过滤就判定永久删除。
正式安装版卸载由Eagle删除安装目录，圈画随目录删除；开发者模式的移除只解除注册，保留源码及圈画。后者是Eagle宿主行为，不通过修改Eagle、安装常驻监控或关闭即清空来模拟卸载。实际卸载验收与已核对的宿主源码区分记录。
独立版及联动后的数据归属见[路线图](roadmap.md#独立版与联动的数据归属)：独立版专门保存、缺失索引与导入导出，不属于本轮实现。

## 媒体与资源的专项约束
格式、UHD尺寸、阈值及120000帧解释见[能力表](releases/motionote-capabilities.md)。常用格式入口、浏览器开发预览、无容量选择、1 GB确认和退出清理按[第二阶段优化方案](experiments/E52/plan.md)实施；实际证据与未验范围见[阶段报告](experiments/E52/report.md)，不把实现与样本通过等同所有素材通过。
当前压缩音轨可无损复制到有界内存播放，不重编码、不写磁盘；未验证起点/编码或预算不足保守回原声，源变化/取消不能静默回退。非零等待、真实听觉同步及长片另验。
完整代理在本次运行内复用仍须核验；失败/退出先确认进程停止、读者释放和归属再回收。退出清理范围包括完整与未完成代理、JPEG序列/帧包、缩略图和其它媒体派生缓存，RAM热帧/预读/图像音频缓冲全部释放。原视频、永久标注、偏好、未知归属和其它活动实例数据保护不变；异常遗留下次启动核验补清理。新策略替代旧持久复用/一天淘汰目标，旧版迁移和上限契约见方案；不是用户点退出就已完成清理。
用户性能监测面板、设置入口及专用采样已删除。内部开发诊断、播放计时与RAM/磁盘预算保护保留；旧用户体验记录、标准测试、report.html及待分析槽不恢复。

## 性能、可靠性与测量口径
| 编号 | 保留的目标和边界 |
| --- | --- |
| P-01 拖动更新 | 环境允许时接近60次/秒；统计实际有效画面提交，不用输入/请求数或无新目标重绘凑数。 |
| P-02 拖动响应 | 定位输入到目标画面提交P95≤50ms；取消/合并/取代、最长停顿及跟手体验同时报告，不冒充物理屏幕呈现。 |
| P-03 首次等待 | 原批准5～30秒样本首次总准备≤视频时长，不足5秒≤5秒；包括读取/分析/生成直到真正就绪。首次和复用单列；长片/新路径不得由旧样本外推。 |
| P-04 资源与稳定性 | 受管RAM/磁盘及在途预留受对应额度约束，连续操作不无界增长；进程/辅助进程峰值与采样范围另列，不等同缓存硬上限。1 GB是确认阈值而非无限制写入许可；本次窗口受管生成物累计计量，确认后仍有物理空间保护，历史实验配额不变。 |
以上是要求，不是已验声明；完整协议见[验证规范](verification.md#性能与证据口径)。不达标须说明并先解决或另行取得产品变更，不能静默降画质、精度或门槛。
