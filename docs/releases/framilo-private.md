# Framilo 自用版

这是用于个人体验和上架前验证的插件，尚未公开发行。可确认版本以Eagle插件信息和包内BUILD-INFO.json为准；当前检查结果及问题见[交接](../progress.md)。

## 打开与使用

Windows x64、Eagle 4.0 Build 22+和Eagle的FFmpeg依赖模块即可使用，无需另装Rust或Node.js。尚未安装依赖时，在Eagle插件中心搜索并安装FFmpeg；插件清单已声明该依赖，Eagle可在安装插件时提示准备它，插件自身不下载或内置FFmpeg/ffprobe。内置的FilmCraft原生组件不是FFmpeg模块。依赖读取与缺失提示沿用现有实现；契约见[官方FFmpeg文档](https://developer.eagle.cool/plugin-api/zh-cn/extra-module/ffmpeg)。在Eagle选中视频，打开Framilo。未选素材时先回Eagle选中，再重新调用插件。

常用入口：MP4/M4V、MOV、MKV、WebM；不同文件的实际兼容情况见[能力表](motionote-capabilities.md)。首次画质随屏幕选择1080p/2K/4K，已有偏好保留、不放大小源；默认显示圈画工具条。原片先播放，代理后台准备。超过1 GB的临时媒体预计占用会询问是否继续；不继续仍可播放原片。

点击画面或空格播放/暂停，滚轮逐帧；拖动画面或时间轴定位。N标注、R片段、B记录、O设置；右侧记录用于回看。循环开启时拖动限制在头尾内，显式编辑端点除外。标注时文字和圈画一起保存，编辑中空格正常输入。画面尚未准确就绪时不允许基于旧帧保存标注。

## 数据与更新

- 原视频不修改。主动保存、编辑、删除文字标注会更新Eagle对应素材；圈画保存在插件的annotation-data目录。保留这两处数据，不能只备份插件程序。仅插件的圈画清理/卸载规则见[数据归属](../product.md#圈画数据归属与删除)。
- memory-settings.json是本机偏好。正常关闭会清理本窗口生成的代理、序列图片等临时媒体，重开重新准备；未知归属/清理失败需核查，不手动删除素材库。
- 你当前在Eagle载入的是本项目plugin目录。源码中的正式运行文件更新后，关闭播放器再打开即可使用；不是另外安装一个插件。名称刷新可能需要在Eagle重新打开插件面板。
- 现有ZIP是自用程序快照，不是官方.eagleplugin安装包；后者由Eagle“打包插件”生成。独立自用包只含运行文件、原生程序、第三方许可和说明，不含素材、偏好、圈画或开发服务。完整解压后可载入含manifest.json的目录；同ID不要并行注册两个副本。

## 回退

日常更新直接作用于本仓库plugin，不需要每轮新包、程序快照或搬迁目录。关闭播放器再打开即可；不覆盖annotation-data、memory-settings.json和未知文件。只有明确的发行/安装恢复验证任务才打包，详见[开发流程](../development-plan.md#日常运行与发行)。

已有自用ZIP以版本和来源提交命名，包内BUILD-INFO记录文件摘要。它们是历史程序快照，不保证旧文件仍在本机；历史构建与未完成清理见[E60记录](../experiments/E60/report.md)。需要恢复时先核对源码/构建配方、原生程序身份、占用和数据兼容，仅替换对应程序文件，不整目录覆盖或带回旧缓存。忽略的二进制可能需要按对应源码重建，不能声称Git可恢复全部运行文件。

回退不能撤销已经写入Eagle的标注；新旧版本未共同支持的偏好可能不生效。重新打开后先核对旧标注和偏好。恢复版本的已知限制仍然存在，不能因为能回退就跳过验证。

## 长期体验

先正常使用，无需手工跑测试或记录每次操作。出问题时告诉我素材名称、最后一步和现象即可；不必上传原片或整库。Codex负责归因、复现和小范围回归。

日常反馈不设固定天数、次数或小时门槛。日常使用继续提供反馈，音画、保存、格式覆盖、连续关闭重开和阻断问题依据实际证据验收。当前修复/验证完成后查阅官方发布要求并准备上架材料；准备材料不等于已提交或发布。
