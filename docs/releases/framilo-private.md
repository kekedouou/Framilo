# Framilo 自用版

这是用于个人长期体验的插件，暂不公开发行。可确认版本以Eagle插件信息和包内BUILD-INFO.json为准；当前检查结果及问题见[交接](../progress.md)。

## 打开与使用

Windows x64、Eagle 4.0 Build 22+和Eagle内已有的FFmpeg模块即可使用，无需另装Rust或Node.js。在Eagle选中视频，打开Framilo。未选素材时先回Eagle选中，再重新调用插件。

常用入口：MP4/M4V、MOV、MKV、WebM；不同文件的实际兼容情况见[能力表](motionote-capabilities.md)。首次画质随屏幕选择1080p/2K/4K，已有偏好保留、不放大小源；默认显示圈画工具条。原片先播放，代理后台准备。超过1 GB的临时媒体预计占用会询问是否继续；不继续仍可播放原片。

点击画面或空格播放/暂停，滚轮逐帧；拖动画面或时间轴定位。N标注、R片段、B记录、O设置；右侧记录用于回看。循环开启时拖动限制在头尾内，显式编辑端点除外。标注时文字和圈画一起保存，编辑中空格正常输入。画面尚未准确就绪时不允许基于旧帧保存标注。

## 数据与更新

- 原视频不修改。主动保存、编辑、删除文字标注会更新Eagle对应素材；圈画保存在插件的annotation-data目录。保留这两处数据，不能只备份插件程序。仅插件的圈画清理/卸载规则见[数据归属](../product.md#圈画数据归属与删除)。
- memory-settings.json是本机偏好。正常关闭会清理本窗口生成的代理、序列图片等临时媒体，重开重新准备；未知归属/清理失败需核查，不手动删除素材库。
- 你当前在Eagle载入的是本项目plugin目录。源码中的正式运行文件更新后，关闭播放器再打开即可使用；不是另外安装一个插件。名称刷新可能需要在Eagle重新打开插件面板。
- 现有ZIP是自用程序快照，不是官方.eagleplugin安装包；后者由Eagle“打包插件”生成。独立自用包只含运行文件、原生程序、第三方许可和说明，不含素材、偏好、圈画或开发服务。完整解压后可载入含manifest.json的目录；同ID不要并行注册两个副本。

## 回退

本轮交付0.2.0-private.4，dist文件名为framilo-0.2.0-private.4-<源提交短号>-win-x64.zip，旁有.sha256，包内BUILD-INFO记录完整来源及逐文件摘要。唯一当前包、测量/清理回执见[E57报告](../experiments/E57/report.md)及[交接](../progress.md)。程序沿用E55减重成果，视频兼容不缩减；不是官方商店安装包。

按用户要求，每轮新包核验成功后替换旧ZIP/校验及解压快照，dist仅保留最新一组；历史文档中的旧路径只作追溯，不保证文件仍在。旧版本源提交/构建清单/摘要另存对应阶段verification-runs（E56/E57），不删除旧测量或冻结Git历史。旧包重建须检出对应源码和匹配打包配方；被Git忽略的task-host.local.exe需按对应.cs重新构建、核对指纹，Git不能直接恢复它。不得把新清单直接用于旧包，也不承诺重建ZIP字节完全相同。

更新前保留对应版本的程序快照。关闭播放器后，只恢复快照清单内的程序文件到原plugin目录；保留memory-settings.json、annotation-data和所有未知文件，不把旧缓存搬回。由Codex核对文件清单、版本、占用和摘要后执行，不建议自行整目录覆盖。

回退不能撤销已经写入Eagle的标注；新旧版本未共同支持的偏好可能不生效。重新打开后先核对旧标注和偏好。恢复版本的已知限制仍然存在，不能因为能回退就跳过验证。

## 长期体验

先正常使用，无需手工跑测试或记录每次操作。出问题时告诉我素材名称、最后一步和现象即可；不必上传原片或整库。Codex负责归因、复现和小范围回归。

观察目标：累计14天、至少10次独立使用、合计8小时，覆盖2次至少65分钟会话。不能自动获取的使用时长由集中回访确认，不安装后台遥测；没有证据的时长保持未确认。这个窗口是观察门槛，不是到期自动成为稳定版。音画、保存、4K/格式覆盖及阻断问题均确认后，再讨论公开发行。
