# Framilo 自用版

这是用于个人长期体验的插件，暂不公开发行。可确认版本以Eagle插件信息和包内BUILD-INFO.json为准；当前检查结果及问题见[交接](../progress.md)。

## 打开与使用

Windows x64、Eagle 4.0 Build 22+和Eagle内已有的FFmpeg模块即可使用，无需另装Rust或Node.js。在Eagle选中视频，打开Framilo。未选素材时先回Eagle选中，再重新调用插件。

常用入口：MP4/M4V、MOV、MKV、WebM；不同文件的实际兼容情况见[能力表](motionote-capabilities.md)。默认720p，可选至4K UHD；原片先播放，代理后台准备。超过1 GB的临时媒体预计占用会询问是否继续；不继续仍可播放原片。

点击画面或空格播放/暂停，滚轮逐帧；拖动画面或时间轴定位。左侧标注/片段/记录/设置按需出现，右侧记录用于回看。标注时文字和圈画一起保存，编辑中空格正常输入。画面尚未准确就绪时不允许基于旧帧保存标注。

## 数据与更新

- 原视频不修改。主动保存、编辑、删除文字标注会更新Eagle对应素材；圈画保存在插件的annotation-data目录。保留这两处数据，不能只备份插件程序。
- memory-settings.json是本机偏好。正常关闭会清理本窗口生成的代理、序列图片等临时媒体，重开重新准备；未知归属/清理失败需核查，不手动删除素材库。
- 你当前在Eagle载入的是本项目plugin目录。源码中的正式运行文件更新后，关闭播放器再打开即可使用；不是另外安装一个插件。名称刷新可能需要在Eagle重新打开插件面板。
- 独立自用包只含运行文件、原生程序、第三方许可和说明，不含素材、偏好、圈画或开发服务。完整解压后可载入含manifest.json的目录；同ID不要并行注册两个副本。

## 回退

本地自用快照为dist/framilo-0.2.0-private.1-70515ca-win-x64.zip；改品牌前恢复快照为dist/framilo-0.1.0-beta.2-494de89-win-x64.zip。每包旁有.sha256，包内BUILD-INFO记录完整提交与逐文件摘要。恢复包保留旧版本号，以494de89识别，不能当成历史Beta2发行包。两者均只保存在本机，详细构建/验证结果见[E53报告](../experiments/E53/report.md)。

更新前保留对应版本的程序快照。关闭播放器后，只恢复快照清单内的程序文件到原plugin目录；保留memory-settings.json、annotation-data和所有未知文件，不把旧缓存搬回。由Codex核对文件清单、版本、占用和摘要后执行，不建议自行整目录覆盖。

回退不能撤销已经写入Eagle的标注；新旧版本未共同支持的偏好可能不生效。重新打开后先核对旧标注和偏好。恢复版本的已知限制仍然存在，不能因为能回退就跳过验证。

## 长期体验

先正常使用，无需手工跑测试或记录每次操作。出问题时告诉我素材名称、最后一步和现象即可；不必上传原片或整库。Codex负责归因、复现和小范围回归。

观察目标：累计14天、至少10次独立使用、合计8小时，覆盖2次至少65分钟会话。不能自动获取的使用时长由集中回访确认，不安装后台遥测；没有证据的时长保持未确认。这个窗口是观察门槛，不是到期自动成为稳定版。音画、保存、4K/格式覆盖及阻断问题均确认后，再讨论公开发行。
