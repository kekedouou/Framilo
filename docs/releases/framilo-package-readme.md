# Framilo

用于视频参考学习的逐帧观察、圈画标注与关键画面回看工具。

## 安装与依赖

需要 **Windows x64、Eagle 4.0 Build 22 或更高版本**。

请在 Eagle 插件中心安装 **FFmpeg** 依赖模块，再安装 `.eagleplugin` 文件，无需另装 Node.js 或 Rust。若提示缺少接口，请确认 Eagle 版本符合要求，并重启 Eagle 后重新打开 Framilo。

## 基本使用与验证

1. 在 Eagle 中选中一个视频，打开 Framilo。
2. 使用空格播放或暂停，拖动画面或时间轴定位，滚轮逐帧观察。
3. 按 **N** 添加文字与圈画，保存后按 **B** 打开记录回看。
4. 关闭后重新打开，确认标注保留，并检查播放与定位是否正常。

## 数据与注意事项

视频在本地处理，原文件不改写。

- **文字标注**：由 Eagle 保存至对应素材；主动编辑、删除会更新该素材的标注。
- **圈画**：保存在插件目录的 `annotation-data/`，不随 Eagle 素材库同步，目前不支持圈画导入、导出。
- **偏好**：保存在插件目录的 `memory-settings.json`。
- **临时媒体**：位于插件目录的 `cache/`，正常关闭时清理本次生成内容。

卸载正式安装版会随安装目录删除圈画和偏好；卸载或更换目录前请备份。素材永久删除后，对应圈画会在后续检查中清理。

解码器、硬件配置和画质会影响流畅度。高画质不能保证完全流畅，代理文件可能占用大量空间，建议优先使用 **1080p 或 2K**。

已知问题：Windows 中文输入法候选框偶尔残留，尚未修复；重新打开可能恢复。

## 原生组件与许可

- Framilo 的部分底层媒体读取与解码功能使用了经修改的 **FilmCraft** 代码，相关版权与许可见 `bin/` 目录。来源为 `storytold/filmcraft 0.13.0`；第三方依赖及源码来源见同目录清单。
- **后台任务保护程序**为 Framilo 自有组件，用于管理媒体进程生命周期，源码随包提供于 `native/task-host.cs`。
- **FFmpeg** 由 Eagle 依赖模块提供，未内置于本安装包。
