# Motionote 当前候选：画质、格式与长视频边界

E51，2026-10-31。此页是当前开发候选的能力说明，不是已发布版或全部素材验收声明；E49冻结标签不变。

后续简化目标见[第二阶段优化方案](../experiments/E52/plan.md)：常用格式、UI预览、1 GB确认和退出清全部媒体缓存。以下仍是E51运行候选事实，不能当成新策略已生效。

用户实测MKV在JPEG路径报“音频时长缺失”；本轮确认原验证使用无音轨短样本，下面的JPEG通过仅适用于这些样本，不构成带音轨/实际全格式支持。报错保护分支已找到，具体文件原因与修复尚未验证。

## 画质与播放方式

- 720p、1080p、1440p、**4K UHD（2160p）**；横片最大3840×2160，竖片最大2160×3840，保持比例，不放大小源。4096×2160的DCI源缩到3840×2025，不承诺原尺寸DCI输出。
- 代理：先读原片，后台生成完整H.264全I帧文件；核验帧映射后接管。为了拖动时每帧可独立解码，代理可能比原视频大很多，不是以缩小文件为目标。
- JPEG继续保留作为兼容后备：先准备整片图片和声音，再播放。它没有默认更高画质的保证；当前q3编码仍有损。超过2分钟时，在当前窗口首次准备该源/画质前确认；可切代理的容器同时给出切换按钮。已有完整缓存仍由原校验流程复用。
- GPU加速沿用原开关及软件回退。4K数据量明显增加，原生GOP缓存、帧像素、驱动与渲染额外占用仍存在；此轮不承诺所有4K/60fps素材连续播放或每次拖动都无延迟。HDR色彩、透明通道保真、旋转与非方形像素组合留在发布前专项验收。

## 格式覆盖

Eagle可导入/生成缩略图的格式不能直接等同本播放器的精确逐帧能力。参考官方[Build18说明](https://en.eagle.cool/blog/post/eagle4-build18)与[额外格式缩略图扩展](https://community.eagle.cool/plugin/f1faafc3-d00e-4f0a-b525-18f7f6ab9159?categoryId=6)建立覆盖目标，实际承诺按下表分层。

| 容器与本轮编码样本 | 代理模式原片定位 | JPEG整片准备/重开 | 当前产品处理 |
| --- | --- | --- | --- |
| MP4：H.264、HEVC；M4V/3GP：H.264；MOV：H.264、ProRes | 软件及硬件偏好路径准确取帧通过；不表示每种编码都走硬件 | 通过 | 开放原片/代理与JPEG |
| MKV/H.264、WebM/VP9、AVI/MJPEG、TS/H.264、MPEG/MPEG2 | 原生桥无法取得可确认的实际缓存PTS | 通过 | 打开时明确选择JPEG兼容模式，不启动未验证原生定位 |
| WMV/WMV2、OGV/Theora | 原生流式读者不支持 | 通过 | JPEG兼容模式 |
| FLV/FLV1 | 样本缺失末帧结束边界 | 同样拒绝，不能猜帧时长 | 明确时间边界错误；不列为支持通过 |
| MTS/M2TS、F4V、RM/RMVB、AV1/HEVC/VP8/VP9裸流与其它编码组合 | 未验 | 仅允许进入有界验证流程，可能因时间戳或编码拒绝 | 目标清单，**尚无兼容承诺** |

原生桥目前实际PTS回执来自MP4读者，不能用“看到了画面”代替帧身份验证。因此JPEG仍有明确用途。这轮没有改上游多容器的时间戳协议，也没有偷偷先转码源文件。

样本均为合成短片；未验证真实Eagle中所有格式的音画、标注写入与长期稳定性。后续按容器×编码×分辨率×帧率×音轨分层，先覆盖基础组合，再对代表性高负载组合做性能/长稳验证，不用扩展名重复测试代替这些变量。

## 容量与时间

代理额度默认5GiB，可选1～100GiB；JPEG维持5GiB。代理生成前估算范围为输出像素×源帧数×0.03～0.25字节，仅作选择提示，**不是保证值**。满足以下任一条件先确认：视频至少10分钟且估计上沿至少1GiB；或上沿达到max(1GiB, 配置额度的一半)。完整且校验有效的现有代理先复用，不重复询问生成。

超额时淘汰可清理的其它旧代理；仍不足或实际磁盘不足时，停止生成、核验并回收本任务未完成文件，继续原片。当前源完整代理、活动读者、未知归属文件受到保护。清理失败保留错误与恢复线索，不能假报清理成功。普通“容量不足，继续原片”结果约2.2秒后渐隐；不完整清理不能自动消失。

120,000源帧上限继续保留，用于限制索引、元数据和跨进程控制消息，不是30秒限制。30fps约66分40秒、60fps约33分20秒；可变帧率按实际帧数。原生索引64MiB、JPEG元数据8MiB、控制消息6MiB及单资产/缓存额度也可能先触发。大音轨、复杂索引或损坏时序不能只按视频时长判断可播放性；超限建议截取需要观察的部分，软件不修改原文件。

E51既有运行实现仍有“设置→高级→能力与边界”入口；用户已要求在第二阶段优化中删除，本文作为开发对话的追溯资料，不再要求产品内展示。完整发布仍须通过第三阶段全素材与长稳验收。
