# Motionote：画质、格式与资源边界

本文供开发评审与发布材料取证，不放入插件设置。实际候选、人工待验统一见[交接](../progress.md)；原始结果见[E52报告](../experiments/E52/report.md)。以下区分入口能力与本地样本证据，不等于全素材支持承诺。

## 播放与画质
- 统一使用原片播放、后台整片H.264全I代理、完整校验后同源帧接管。GPU开关、RAM额度、预读和准确帧保护保留；本轮没有改变代理编码配方。
- 日常JPEG模式及兼容切换已撤下，旧JPEG偏好读取迁移到proxy，不重置其它偏好；旧实现仅保留共享依赖/回归和旧缓存清理。
- 默认720p，可选1080p、2K（1440p）、4K UHD（2160p）；保持比例、不放大小源。UHD横屏框3840×2160，竖屏反向；DCI宽幅按框缩小，不承诺HDR/透明保真。

## 常用格式证据

| 入口/编码 | 本地原生独立对照 | 声音证据与限制 |
| --- | --- | --- |
| MP4 / M4V：H.264、HEVC、AV1 | 合成短片首/中/末/回跳实际PTS及参考帧通过；UHD30和720p60的BT.709样本通过 | AAC包边界已读取；音轨复制不满足边界时回原文件读取，真实Eagle音画待验 |
| MOV：H.264、BT.709 ProRes | 同上；ProRes的明确BT.709 720p样本通过 | PCM原文件HTMLAudio加载、seek和播放时钟通过；未标色彩的ProRes本轮拒绝，避免错误颜色 |
| MKV：H.264、HEVC | 实际PTS回执修复；缺流级时长、非零起点及VFR样本通过 | AAC原文件HTMLAudio时钟通过；用户原报错素材未定位复现，不能声称该素材已验 |
| WebM：VP8、VP9 | 实际PTS与首/中/末/回跳通过，含无声样本 | Opus原文件HTMLAudio时钟通过 |

上述均是Windows本机原生工具/独立浏览器的合成样本检查，不是Eagle音画同步、GPU全组合、标注读写或长稳验收。未标色彩的高清样本在FilmCraft与FFmpeg默认矩阵选择上出现约6.6/255的平均通道差，明确BT.709样本约0.44/255；前者仍列未验，不能把它藏进通过名单。

只开放MP4、MOV、MKV、WebM扩展名，M4V作为MP4别名。AVI、TS/MTS/M2TS、MPEG/MPG、3GP、WMV、OGV、FLV/F4V、RM/RMVB及裸流不在本轮范围。编码、音轨或色彩不满足准确读取条件时简短拒绝，不以JPEG或无声播放掩盖。

## 临时存储
- 不提供磁盘额度设置。1 GB为十进制1,000,000,000字节，按本次窗口累计生成物估计；预计超出先问“继续生成 / 继续播放原片”。不是一到1 GB就报错的硬上限。
- 实际超出估计时停止编码并回收未完成输出，确认后最多重启一次。取消、关闭、换代次不得恢复旧写入；原片可继续操作。
- 同意后仍保留2 GiB物理余量和100 GiB内部保护，跨窗口预留串行核对；实际磁盘不足则停止生成，不牺牲原视频或永久标注。
- 新媒体生成物位于`plugin/cache/sessions-v1/<窗口id>`。正常关闭先停进程/释放租约，再清理完整、未完成代理及其它派生缓存；RAM/对象URL随读者与播放器释放。重开重新准备。
- 异常退出只能在下次启动证明旧owner及后代已退出后补清；出生身份缺失、未知文件和活动实例保留。旧JPEG/代理不再跨次复用，首次升级正常关闭时迁移清理可确认的旧数据；无充分身份的旧租约保留，不能保证所有历史残留都自动清零。
- 原视频、Eagle库、annotation-data、用户偏好、必要错误回执和开发证据不在清理范围。受管RAM上限不等于整个Eagle/显卡进程占用上限。

## 长视频边界
120,000源帧护栏不变：30fps约66分40秒，60fps约33分20秒；VFR按实际帧数。索引64MiB、控制消息、音轨和在途内存边界也可能先触发。它们保护界面、定位与资源安全，不是旧30秒限制。全素材与长时间使用在第三阶段集中验收，当前不发布。
