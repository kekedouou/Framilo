# 数据说明

## 本地处理

Framilo 在本机读取所选视频及相关素材信息，用于播放、定位和标注，不改写原视频文件。

Framilo 本身不主动向开发者服务器上传视频、标注或使用记录。Eagle 及依赖模块自身的下载、更新行为由对应软件管理。

## 保存位置

以下文件路径均相对于插件目录。

| 数据 | 保存位置 |
| --- | --- |
| Eagle 文字标注 | 由 Eagle 保存至对应素材 |
| 圈画及绘图工具创建的画面文字 | `annotation-data/` |
| 偏好设置 | `memory-settings.json` |
| 代理及其他临时媒体 | `cache/` |

圈画不随 Eagle 素材库同步或迁移，目前没有内置导入、导出功能。Eagle 文字标注与绘图工具创建的画面文字属于不同数据，备份时需分别考虑。

## 修改与删除

- 主动保存、编辑或删除文字标注，会更新 Eagle 对应素材。
- 同一帧的多条文字标注共享该帧圈画。主动删除最后一条文字标注时，会同时清除该帧圈画；仍有其他文字标注时保留。
- 素材移入 Eagle 回收站时保留圈画；永久删除后，插件会在后续检查确认素材不存在时清理，并非即时删除。
- 素材库离线、查询异常或文件归属不明确时，不会据此直接清理圈画。

## 临时媒体

代理文件可能占用较多磁盘空间。预计本窗口临时媒体累计超过 **1 GB** 时，会询问是否继续生成；选择不继续时仍可播放原片。

正常关闭时，在媒体任务停止后清理本窗口的临时内容。异常退出后的残留，需在后续启动确认相关任务已停止、文件归属明确后再清理。

缓存清理不删除原视频、永久标注或偏好。重新打开视频可能需要重新准备代理。

## 备份与卸载

请分别备份 Eagle 中的文字标注，以及插件目录内的 `annotation-data/` 和 `memory-settings.json`。仅备份程序文件不能保全标注数据。

卸载正式安装版会随安装目录删除圈画和偏好；更换或删除插件目录前也应备份。开发者模式下移除入口仅解除注册，与正式安装版卸载不同。
