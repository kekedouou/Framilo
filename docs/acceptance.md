1. 名称/图标、空选中/不支持状态；此前失败的MKV及常用MP4/MOV/WebM音画，适用时检查4K/竖视频/窗控。
2. 用户自行选择可测试素材，保存/重开/编辑/删除一条文字与圈画；保护同帧其它文字和圈画。这是用户操作，不授予代理批量写入权限。
3. 原地暂停续播、快慢拖动、松手准确帧、滚轮、循环、密集标注、记录、输入法、设置与GPU开/关；用户监测入口已撤下。
4. 原片播放和代理准备中关闭，再打开确认标注/偏好仍在，临时媒体重新准备；拒绝大于1 GB的准备后仍能播放原片。
