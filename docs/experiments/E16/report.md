# E-16：右键交互与标注输入精简记录

2026-10-22，基线e26c205，范围和最终确认见[计划](plan.md)。本地实现及适用自动检查完成；真实Eagle体验尚未验证。

## 实现与行为

- 右键一级120px、类型二级132px，背景透明与弱边框参照112px左键轮盘。正常观看四项保持；按模式处理短点，输入框保留系统菜单。短点、长按/甩动、回中心、二级刚展开、Esc、失焦、丢捕获/按键、切源分别处理，不将轮盘取消当保存。菜单开启时Esc有优先级，先关菜单、不取消草稿。
- 选区R/右键短点共用finish：完整不同帧确认并循环（包括未改动旧范围）；未齐取消退出；同帧清除并退出/关闭循环。顺序仍钳制，允许重合端点。右键左/右显式控制头/尾，有端点先准确定位；未设端点只选控制对象，之后画面/时间轴/逐帧设置该端点，显式控制优先于“下一未设端点”。Esc恢复旧范围，待定位/切源保护保留。
- 圈画一级仅上类型/右颜色/下橡皮/左撤销；移入类型展开五类，继续移动松开选择，刚展开原地松开不误选。颜色保持紧凑色板；删除/H显隐/D/Enter保存等原快捷键保留。工具条只通过设置控制，默认关并记忆，保存设置不重建媒体、不改变固定标注帧。
- 时间点文字移到画面下方、时间轴上方，只在该处输入；侧栏显示草稿预览，正常编辑无保存/取消按钮。Enter或画面右键短点保存，Shift+Enter换行、Esc取消；输入法选字及紧接选字的Enter不提交。空白新建/清空旧标注都取消，旧原文不删；失败保留，保存中不重复发起，未知先只读核对。删除确认/未知/过期等原异常处理入口保留，不把它们当正常添加界面。

## 持久化盘点与检查

仅Preferences的既有memory-settings记录新增兼容可选drawingToolbar布尔值，owner/4KiB上限/原子暂存替换不变；缺省false、读旧文件不迁移。读写端为preferences的interactionValue/default/read/save，Session初始快照/setPlaybackSettings（保留新字段）及新增setDrawingToolbar，UI应用设置/独立工具条勾选，app仍经原构造入口读取。永久圈画/原生文字格式不变，全部测试写入内存替身或专用scratch。

真实隔离文件六项：旧记录原样读取；工具条保存/关闭/重开；另一设置入口不丢字段；写入中途失败/已存在未提交暂存保护；提交后中断重开；无效类型/未知字段不覆盖。提交前中断保持旧完整值，提交后中断重开读新完整值，不将丢回执说成未落盘。原设置并发/链接/限额检查保留。原生文字Session新增空白新建/清空旧文零写入取消检查。

## 原始失败与修正

新模型先在旧实现六项失败，保留输出。旧纯检查中“为尾预留一帧”“未改旧范围不播放”“同帧留在编辑”断言与新批准行为冲突，按新规则调整；旧E-14正向拖动原会被钳制到尾前一帧，如今可达到同帧并清除，因此改用仍合法的反向调整，另保留同帧清除专项。偏好旧对象精确比较补false，未放宽格式校验。

浏览器真实发现Escape在Window目标与多个注册处理器间先进入圈画退出确认，原失败/诊断保留；为UI/圈画注入菜单活动判定，令Esc先交菜单处理，不改为绕过退出保护。最终合成输入仍覆盖该目标顺序，不能据此断言用户实际Eagle曾遇到同一路径。

完整回归还检出旧空白保存应报错留在编辑、时间轴未修改/改回原范围不播放等旧断言，按本次取消/确认规则调整，并保留零写入、原文保全、Esc恢复、重复保存、未到位与切源等检查；未删除相关检查或绕过默认入口。
