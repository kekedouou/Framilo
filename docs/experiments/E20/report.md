## 九项对应

1. 官方无边框要求main.frame=false，当前正式manifest已是false，增加黑色窗口背景。截图白条属于原生系统窗框，网页无法移除；必须由Eagle重新加载manifest并创建新窗口确认，本轮未操作已安装插件，不能宣称宿主白条已去除。依据[官方无边框文档](https://developer.eagle.cool/plugin-api/tutorial/frameless-window)。
2. 观察区域改纯黑，取消两侧人为14px边距；完整等比，不拉伸/裁切源画面。比例不同产生的黑边及源视频自身黑边保留。
3. 记录改按帧key增量复用，视口窗口未变化不重排；离开范围才释放canvas和预算，异步结果检查所属卡片。滚动不再清空全部画布。
4. 左键手势保留原语义，采用同系半透明扇区/矢量箭头/短标签和方向高亮，不改定位算法。
5. 缩略图按源比例生成与显示，不添加固定16:9填边，卡片间距4px；记录右缘可拖，支持键盘左右调整，宽度限200至560并随窗口收缩。
6–8. 工具轨固定左侧中部、记录在其右侧展开、设置在记录右侧悬浮，工具不跳到左上角。标注进入后输入框放在视频区域下方，时间轴暂隐；记录已展开时输入仍在记录区。
9. 时间轴36px操作区、4px线、20×32px标注命中、28×34px端点命中，不恢复时间/帧数读数。
