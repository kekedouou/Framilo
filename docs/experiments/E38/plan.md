## 实施与验证

复用正式 Player 请求及 Canvas 事件，以 renderer 单调时钟测量。新增独立采集、报告、测试、界面模块；Eagle/素材写入和媒体算法仍由现有模块负责。配置/来源/代码快照绑定每轮，默认关闭；独立播放器生成事实报告，不调用 AI。

默认模型覆盖完成、暂停、取消、失败、缺素材、截断、不可比较、坏报告。新增独立浏览器只读真实媒体链路验证，最多三次诊断运行，每次不超过十分钟；若需准备媒体，仅在本轮隔离目录，新增输出总量不超过 512 MiB，不恢复历史封存测试额度。不导入素材、不写标注、不清用户缓存。自动标准测试每个场景三次，读取已打开素材；实际条件记录在报告。

产物固定在 artifacts/performance；运行时安装目录的 performance-reports 明示未同步，导入脚本才更新工作区状态。达到容量停止新记录，保护所有已有报告。验收包含真实链路报告、完整性拒绝测试和监测开销计量；独立浏览器不代替 Eagle 实测。完成后只诊断、交付并停止。
