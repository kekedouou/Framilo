1. 原片连续播放不再把所有迟到帧丢弃：按音频时钟显示仍有效的最新帧，解码返回后继续有界前读；暂停/跳转的过期结果不能刷回。原生4K→1440p非整数缩放改在YUV平面进行，避免整张4K CPU RGBA展开和四通道缩放。所选分辨率不降低，准确源PTS、逐帧及标注保护不变。
2. 高级设置新增代理磁盘额度：1/2/5/10/20/50/100 GiB，默认5。整片代理独立计费，JPEG保留旧5 GiB。生成前清理最近最少使用的旧源代理，活动读者/当前源/写入任务/身份不明文件保护；估计不足时再清剩余可淘汰代理、最多重试一次。单片超过额度或实际硬盘已满仍需提示，原片继续可用。
3. 删除代理条及设置入口；旧偏好字段仅兼容。当前仍为原片直读＋后台完整整片代理，不是分段代理。
4. 性能监测只即时显示等待/阶段及插件RAM、当前视频受管RAM、总缓存磁盘、本视频磁盘。打开前已开始的原生请求也能显示累计等待。关闭停止采样；无体验记录、标准测试、导出、报告入口。高级设置资源状态小字撤下。
5. 旧report/runner/inbox/protocol等不再由运行入口或原生发行清单引用。保留通用有界采集、阶段计算及功能回归；不建立新的用户报告架构。
