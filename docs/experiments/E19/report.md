# E-19 正式石墨播放器本地实施记录

2026-10-23。状态：代码与本地检查完成；真实Eagle/用户体验待验收。当前正式开发入口plugin，未安装或发布新版本，未读写真实素材标注。

## 已实现

- 顶栏原生窗控接线，右侧触边图标工具轨、细时间轴、记录单列缩略图与选中详情、悬浮设置及折叠高级区。
- 轮盘分割扇区、矢量图标和短标签；类型原中心外圈展开。轮盘/工具轨/标注框统一alpha半透明，无逐帧背景模糊；短淡入/淡出、工具轨位移，遵循减少动画。
- 同一源帧统一文字/圈画；同帧多条文字显式选择；失败保留草稿、部分成功不重复写、未知结果只核对、空白不删除旧文字。输入法期间及刚结束时阻止轮盘触发保存。
- 记录视口最多10张240×135画布，使用共享预算、低优先级读取；播放不启动缺失缩略图解码。关闭/换源/销毁释放；箭头、文字、椭圆及擦除遮罩完整显示。暂时拿不到预算的预览保留占位，不挤出播放缓存。
- 发行白名单补入新正式UI文件；未改播放时钟、源帧定位、永久存储格式或冻结发行包。

## 失败、修复与限制

初始默认检查遇到沙箱硬链接权限限制，改用已批准隔离目录的沙箱外检查；随后修正旧测试的缓存条默认值、发行白名单遗漏。真实DOM检查揭示旧时间轴留白和轮盘整圆底色叠加，已修正。修复同帧选项迟到、设置期间背景操作、工具按钮误传事件对象、虚拟滚动位置和反复UI重建后设置控件重复问题。所有失败日志保留，不覆盖旧证据。

本轮没有与旧正式版的真实媒体性能对照，因此不声称达到最快响应或已经解决所有卡顿。原精确定位和播放模型回归通过；真实Eagle窗控/F11、不同缩放/全屏、视频切换后拖拽、音画同步及长期RAM必须集中人工验收。独立浏览器不能证明Eagle体验。未重新运行封存实验或扩增UI-05预算。
