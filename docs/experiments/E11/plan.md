# E-11：同帧圈画与原生文字统一、局部擦除

2026-10-22用户批准开发，基线2bc30b7。沿用plugin正式入口；引用R-03/05/08、P-04，接续E-10而不重写历史。冻结Beta、原性能/长期稳定性缺口不变，不做整体UI重设计或带图形导出。

## 批准行为

- 同一实际源帧一组图形，D进入/再D保存退出；已有图形继续编辑。输入框、中文选字、长按重复不误触。Enter保存、Esc退出保护沿用，失败保留草稿。
- D关联当前帧全部Eagle原生文字；无文字时在保存而非进入时创建一条原生文字。说明优先显式文字，其次图内文字，否则“第N帧”；不自动覆盖已有原生文字。取消不新建。N在同帧已有文字时编辑；优先当前选中条目，否则多条需选择。
- 多条原生文字分别保留、共享同一组图形；删除一条只解除该关联，共享图形保留；外部删除最后一条仍保图并提示。清除图形不删文字。旧同帧图形合并编辑时保全全部对象、源身份和原始记录，不静默覆盖。
- 真局部橡皮擦覆盖手写/箭头/矩形/椭圆/文字；擦除轨迹随对象变换，保存重开保持，连续一次擦拭算一步撤销。限制轨迹及历史预算，不能涂改原视频/截图或光栅化整个标注。
- 绘图滚轮调整字号/线宽，橡皮状态调擦除直径，普通观看仍滚轮逐帧。小号线形画笔标识替代◇圈画；变换控件视觉收敛、实际抓取范围保留。
- 淡入淡出按视频时间在标注帧前后显示，图形仍归属一个准确源帧；编辑固定原帧、完全显示，H仍控制可见，图形不写进视频缓存。前后各0.25秒统一淡入/淡出，允许重叠；新出现的组在旧组上方。用户已确认。
- 沿用中性深灰#262626、主字#e8e8e8、次字#9aa0a6、边界#575757、选择色#536077，Segoe UI/微软雅黑；紧凑浮动工具，不改变视频布局，动画不加入媒体渲染或阻塞定位。

## 实施与兼容

drawing-model负责可校验的对象/局部擦除与变换；drawing-ui负责SVG掩膜、工具/输入和按视频时间透明度；drawing-session负责单帧共享组及关联；session协调原生读写，只经eagle适配层。drawing-store兼容旧记录、严格校验新增关联/擦除字段；原子版本写入、源变化保护、缓存清理不碰annotation-data。

原生文字与本地圈画不具备跨存储原子事务。按创建前读回、发出回执、结果核对、最后保存本地图形执行；未知结果只核对，不重复添加。保存任何部分失败保留图形草稿，后续重试不重复写Eagle；保存/核对期间禁止修改对象或静默关闭。正式用户主动保存属产品行为；自动检查只用替身/隔离文件，不擅自真实库写入。
