# UI-01：视频优先交互样稿

2026-10-23用户批准隔离样稿，随后改为右侧隐藏入口、右侧缩略图记录栏与邻近入口的悬浮设置。六张生成效果图未获认可；用户要求停止生成图片。本轮直接以HTML/CSS/JavaScript制作可操作样稿，不把生成图作为界面资产或验收依据。

## 目标与授权边界

检验右侧入口是否容易发现且少打断观察；比较玻璃材质、尺寸与轮廓的真实呈现。代码仅放prototypes/video-first，不修改plugin、真实Eagle数据/配置/缓存，不加载安装插件、发布或新增依赖。背景采用浏览器实时绘制的合成场景和内存示例记录；不重写或替换正式播放器核心。浏览器模拟不承担R-02/03准确帧、R-05/08真实持久化和P-01～P-04性能/资源验收。

## 已确认交互

- 默认视频居中、完整显示；底部仅细时间轴、标注点、片段头尾，无播放/倍速按钮、秒刻度和帧/时间数字。缓存条默认关，仅保留显示开关。
- 右侧触边显出标注/片段/记录/设置四个图标，无常驻文字；保留键盘焦点和悬停提示。首次一次非阻断操作说明可关闭/重看。操作、编辑或聚焦期间不误收起。
- 记录从右侧展开；沿用用户已接受的视频让位、关闭恢复。每源帧一卡，卡片仅缩略图，预览叠该帧圈画；选中后在侧栏上方显示短信息，多文字仅聚合展示不合并。打开继续播放，点击记录跳帧暂停；保持展开，关闭不续播。
- 统一标注：暂停固定帧，下方文字框与画面圈画同时可用，无暗幕，进入编辑不移动视频。因记录已从底部移至右侧，样稿编辑保持已打开侧栏所占几何空间并在画面下方悬浮文字框，退出恢复记录，避免把文字框迁回侧栏。画面右键/Enter保存，Shift+Enter换行，输入区系统右键/输入法保护；空白新建取消，编辑不因清空文字删原文。失败/部分成功/未知结果模拟需保留草稿且不重复新增。
- 观看右轮盘左片段/上标注/下记录/右循环；圈画撤销/类型/颜色/橡皮及类型二级，片段头尾/确认取消沿用批准行为。无片段循环提醒合计不超过2秒，错误保留。
- 设置浮在右侧入口附近，不居中或挤画面；打开暂停、关闭仍暂停。资源项折叠到高级区，后台策略不改。全屏入口位于右上，支持F11。新界面不放导出。
- 实验控制独立lab页面，提供材质透明度、面板宽度、圆角及收起延迟等少量参数；命名版本保存在专用浏览器存储，可导入导出JSON并切换比较，不含媒体或标注数据。

## 本轮视觉与实现取舍

沿用Segoe UI/Microsoft YaHei；底色#101113、表层#25272a、文字#f0f0ed、次级#a6a9ab、边界#ffffff24。特色集中在右侧小尺度凹口与有间距的玻璃图标，取消大幅波浪、发光圆环和整幅滤镜。记录栏以缩略图层级组织，设置使用局部backdrop-filter与细内高光。真实CSS参数可调整，不将这组初值当作视觉定稿。

## 验证与停止标准

Node纯状态检查：同帧聚合/新建空白/清空旧文/部分保存重试/未知核对、选区未齐/同帧/取消恢复、版本导入边界。独立Chrome检查实际DOM/布局：入口显隐与焦点、统一编辑无移位、记录恢复、设置暂停、文本/圈画、窄窗/竖屏/减少动画、版本保存及重开。人工判断关注是否找到入口、玻璃可读性和是否抢画面；真实Eagle未验。

测试不调用历史媒体或清理实验。新证据verification-runs/ui01，最多24文件/总16MiB；独占浏览器临时目录总128MiB止线、单轮60秒、最多3轮，结束核对身份与路径后清理。保留必要失败与最终布局截图，不新增AI图片。原正式文件指纹须保持一致。

结果见[报告](report.md)。样稿进入正式播放器需后续明确批准。
