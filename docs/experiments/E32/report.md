# E-32 轮盘响应与工具统一

2026-10-24，范围见[计划](plan.md)。本地模型及独立Chrome验证通过，真实Eagle未验。

## 改动与原因

旧二级切换会重建根扇区/SVG、重设轮盘位置，types分支还会切换动画名，导致整个轮盘重新入场。现在每次打开仅构建一次根和两组外圈；分支切换只改显隐，外圈保留70ms淡入，根动画不重播。悬停240ms降为100ms；取消、来源变更、右键松开和长按420ms规则保留。

工具选择共用的chooseTool以前直接打开属性；现在关闭属性，主动属性按钮仍可用。文字框与左侧共享rgba(23,25,28,.58)透明底和6px模糊；轨宽50px、按钮宽38px、高亮rgba(110,181,231,.22)。设置关闭后再调用标注/片段，原草稿保护及播放状态不变。

## 验证

证据目录verification-runs/e32-wheel。默认检查通过（105份文档、725条本地链接），无媒体生成/真实库写入。轮盘11项模型检查覆盖100ms边界、切换取消、30次复用及销毁无遗留监听器；Chrome155常规142项、小窗口720×480减少动效140项通过，页面异常0。浏览器确认切换二级没有子树替换、没有全盘入场动画重启，135ms观察点已展开；这不是Eagle渲染耗时或GPU性能测量。

命令：node scripts/check.cjs --without-prepared-host；node tests/support/drawing-browser.cjs --e32 --wheel-screenshot e32-final-wheel.png；node tests/support/drawing-browser.cjs --e32 --e18-compact --e18-reduced e32-final-compact.png。截图已检查，文字框局部模糊可见；工具轨左右同边，设置与记录分区保持。

保留失败证据：新增fixture首次变量重名，在Chrome启动前被语法检查拦截；首次浏览器发现工具类型区滚动条挤偏按钮，调整滚动区内边距/宽度后几何通过；第二次浏览器的片段检查错误地把已有片段当空片段，按原有清除/创建两种语义修正测试，未改产品规则。最终两轮均通过。总共4轮Chrome，临时目录由既有归属清理器回收并留回执，无遗留运行服务。
