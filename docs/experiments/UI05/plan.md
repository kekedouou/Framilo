# UI-05 石墨编辑室完整隔离样稿

用户选定 UI-03 A，要求完成可用设计；新参考明确轮盘采用图标、标签、扇区和外圈二级结构。仅 prototypes/video-first/graphite，正式 plugin、库和接口不变。

## 设计与复核

- 色板：画布 #202124、顶栏 #28292d、记录 #303135、信息层 #37383c、文字 #eceef0、选中冷灰蓝 #7895ad。金色不作为界面色。
- 字体：Segoe UI / Microsoft YaHei UI；标题14、正文13、辅助11。保持视频为主，不增加大标题和装饰数字。
- 顶栏轻量窗控；视频居中；右侧工具轨贴记录栏左缘；记录纵向单列。设置悬浮，编辑保持画幅。
- 轮盘中心取消、内圈四方向、类型外圈五项；图标与短标签同时出现，扇区缝隙分层。参考的金色和过多菜单不照搬。
- 复核：区别不来自新增装饰，而来自明确的径向操作层级。默认观看不常驻轮盘，不牺牲画面给设计展示。
