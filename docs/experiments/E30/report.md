## 实施

- 窗口创建、主动再次调用依次show/focus；异常不阻断播放器初始化。不使用全系统永久置顶。真实被Eagle压住的问题仍需宿主复验。
- 记录缩略图移除每张250ms固定等待，串行并让出绘制帧；关闭记录有界保留，重新打开复用原canvas。活动及保留总数不超过20，仍走Player原RAM租约。换源/记录变化/销毁释放，失败1秒后重试，播放不抢占缺失帧解码。首次未准备帧无法保证零等待。
- 设置与工具直角、半透明、局部6px模糊；轮盘扇区4px轻模糊，记录保持纯色。无全屏背景滤镜。
- 类型与颜色连续240ms悬停展开；经过其它根项取消旧等待/分支。二级图标/色块，无可见文字，保留无障碍名及悬停提示、自定义色。
- 设置按用户指定三级展开，原控件/应用及即时生效监听保留，原设置保存状态直接显示。小窗口三列缩窄、分别滚动且垂直居中，不覆盖右记录。
