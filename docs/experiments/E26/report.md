# E-26 本地实施结果

本轮六项已写入正式plugin，R-02/R-05/R-08及既有P标准保留。未改媒体核心、标注格式、Eagle写入接口或配置保存规则，未安装/重新加载插件、未操作素材库。

- 顶栏全屏时接收拖动，移动超过6 CSS像素分发一次windowed，由app调用既有setFullScreen(false)。显示后的最上缘也可拖动，窗口模式保留原生拖动。浏览器只验证事件分发，真实Eagle退出全屏后的窗口位置/跟手程度未验证；没有引入新的宿主移窗API。
- 右侧记录上下各44px留白。缩略图悬停/主动选择显示两侧3px淡蓝竖线，不随播放帧自动选择。统一细滚动条，移除上下箭头。记录编辑复用顶部信息区，输入框可选字，其他界面文字不可选；缩略图仍显示但编辑期间禁用跳转，防止中途换帧。
- 设置按画面与标注/操作分组；高级按缓存容量/准备与清理分组，在右侧独立弹出，两者分别居中，小窗口内部滚动。悬停/焦点450ms显示说明，离开收起。点击外部关闭两个面板，不顺带播放；关闭后保持暂停。主次面板均可见设置应用结果，失败不自动淡出。
- 新settings-view仅负责布局和展示，复用原控件监听器。反复销毁/重建还原控件，断开观察器和事件；隐藏设置时不读取面板尺寸。运行文件已纳入正式入口和发行文件清单，不生成发行包。
