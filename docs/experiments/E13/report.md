# E-13：六项体验修正与2K试接记录

2026-10-22，基线d9498ed，开发代码在同一plugin入口，本地实现完成。用户本次截图是问题来源，**尚未取得修正后的真实Eagle人工验收**；不把旧E-11/E-12交付或本地检查补记为本轮体验通过。范围见[计划](plan.md)。

## 结果与原因

1. **高倍速供帧停止**：原预读顺着后面12个相邻源帧解压，高倍速时其中一些画面不会在下一次屏幕刷新展示；两条任务槽仍可能忙于这些帧。150ms缺帧保护此前直接转error。现在按实际刷新间隔、倍速和源时间表预读接下来要显示的帧；确实缺帧时停声音/时钟、固定一帧缓冲，到位后从该帧同步继续。暂停、定位、切换/关闭用代次取消旧恢复，缓冲期间按钮/空格/画面单击可暂停。真实损坏仍报错，不提高RAM、并行任务数或150ms阈值；正常逐帧仍访问每一个准确源帧。快放不会承诺展示超过屏幕刷新率的全部源帧。
2. **画面文字框**：使用实际字宽测量增长宽度，wrap=off，只以用户输入换行增加高度；移除垂直滚动控件，超过画面可用宽度才水平查看。右上角×只删除当前文字对象，可Ctrl+Z恢复，不删整条原生文字/其它图形。
3. **淡入淡出**：设置0～1秒，默认0.25秒，按视频时间在前后各该时长淡化；0只在实际源帧完整显示，按源帧序号判断，避免变帧率时只在精确时刻闪现。点击应用/记忆，暂停原位，不重建媒体；显隐H仍即时独立，重叠和新出现组居上不变。
4. **画面单击**：左键短点播放/暂停；移动越过阈值后即不再视为点击，即使回到原地。拖动/长按、其它指针、取消/失焦、编辑/输入等不误触。缓冲时点击可取消自动续播。
5. **2K试接**：选项2K（1440p），横屏2560×1440，竖屏1440×2560，保持比例、不放大低尺寸、匹配尺寸标原始分辨率。应用后保留帧/暂停并记忆；720p、1080p、1440p独立缓存，共享原5GB/一天/LRU规则。RAM默认1GB和已选额度不变。原E03/E04复现脚本显式固定原双画质矩阵，避免新增QUALITIES使历史命令错误扩项/占用旧证据。
6. **倍速反馈**：只有Z/X/C用24px暖黄色左上角提示；上下短甩沿对应方向显示28px倍速，持续拖动/长按后在方向盘中心。竖向操作收起左右提示，避免压住中央数字；边缘位置与方向盘对齐，换源清除旧提示。0.1～4×及步长、Shift/Ctrl、停止移动不继续调速不变。整体UI未重做。

## 失败与修正

旧测试原本要求缺帧转error，已按本轮产品修复改为缓冲与取消断言；第一版供帧测试跳过首次应显示帧的时钟采样，修正为明确的40/100/80ms采样，不放宽恢复标准。三档缓存测试最初误把磁盘manifest当作带路径的已租用资源，改为实际finish取得租约后核对/释放。绘图文字测量初版依赖doc.createElement，使旧最小DOM替身无法运行；最终复用已有画布上下文测字，无测字能力的模型沿用几何近似。首次失败和最终原始输出均保留，没有用失败的测量器断言产品性能下降。
