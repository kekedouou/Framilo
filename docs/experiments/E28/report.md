## 修正与依据
- 工具轨原positionTools根据高度下移dock，是入口跳动的直接原因；现保持dock位置，工具轨在上方可用范围滚动。
- 原nativeDeleted无条件保留圈画；改为确认原生删除成功后，根据最新读取的同源帧文字决定保留或连带删除。覆盖存储链接之外后来新增的同帧文字。外部删除不清理圈画。
- 原生/圈画删除均在记录详情原位确认；复用原保存/核对入口。右键/Esc取消只在安全状态有效，未知结果仍先核对。圈画清理失败保留可见孤立记录，可单独删除而不重发原生删除。
- 循环启用且范围有效时按源帧序号闭区间过滤，范围变化回到列表顶部，以180ms淡入/轻位移过渡；关闭循环还原，减少动画偏好禁用过渡。
- 原toast仅识别五句固定成功文字，其他普通提示会常驻；改为普通提示统一定时，后一个使前一个提前渐隐。失败、未知、未保存信息保留。取消无标注启动toast，记录区可显示空状态。
- 全屏前缓存窗口尺寸/最大化状态；拖动恢复时跳过两次SDK查询，缓存缺失时并发探测。连续移动每次调度仅提交最新位置，串行无重叠。保留抓取比例、鼠标位置和松开结束规则。
