# E-27 工具轨与窗口拖动

用户批准五项正式修正：记录列表可视区上下保留固定12px内边距，滚动时底部也保持；记录仅悬停用较暗蓝边线、选中不着色；工具栏在标注按钮上方竖排，关闭在最上、手写最下、保存为对钩；标注按钮再次点击走原退出保护；全屏拖动恢复窗口后仍以标题栏抓取位置跟随鼠标，松开结束。

沿用frontend-design已确定的纯黑/深灰/淡蓝、原字体和小圆角。工具栏紧凑纵向排列；高度不足时工具轨内部滚动并将入口下移至可用区域，不裁切属性弹窗。R-02/R-05/R-08和P标准、保存失败/未知结果与草稿保护保留。

Eagle窗口getSize/setPosition/setFullScreen已核对官方文档：https://developer.eagle.cool/plugin-api/zh-cn/api/window 。宿主移动独立模块负责，UI只发手势事件，异步移动合并，不修改媒体核心。需模型验证恢复等待、连续移动、松开与失败；浏览器验证工具轨/留白/退出保护，真实Eagle拖动仍单独验收。

预算：最多5轮独立Chrome、每轮90秒/128MiB临时profile，证据50MiB，默认非宿主回归；不操作真实素材库、不安装插件。
