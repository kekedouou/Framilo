## 交付行为

- D新建当前源帧圈画，原有标注从列表“添加圈画／编辑圈画”进入。暂停后核对真实frameId/ordinal/time，编辑锁住定位/播放/设置/清理/导出；保存/取消后保持暂停。五工具、选择移动/角点缩放、Delete、Ctrl+Z/Y、常用颜色/线宽/字号、中文多行文字均已接线。输入法选字不误触Enter保存。
- 独立SVG层不改picture颜色路径，不创建另一份视频位图；坐标归一化，按实际画布比例扣除留黑，窗口变化不改变原视频区域。普通查看显示当前准确源帧的圈画，编辑只修改明确选中的一条，同帧多条不合并覆盖。
- H与设置即时显隐并独立持久保存，不需应用或重建视频；列表/时间标记保留。进入编辑临时显示、退出恢复偏好；编辑H仅临时对照，隐藏时不接收笔画。点击绘图层会从工具选择框收回焦点，随后可直接Delete/撤销/Enter；其他界面焦点重设计仍留UI阶段。
- 文字与圈画统一列表，但不把图形塞进Eagle文字备注。纯圈画不创建原生占位文字；清除圈画保留文字，整条删除确认。原生删除或改变关联文字时间时，圈画保留为独立条目并提示。原生时间与真实源帧时间分别记录，避免时间落在帧中间就立即被误判为失联。整条原生删除只有在既有API读回确认后清除关联圈画；结果未知不重复删除，局部清除失败保留图形并提示。
- 有修改时关闭/重载/资料库切换，先保存后继续、放弃或返回；保存失败展示错误、保留草稿和窗口。同步原子保存结束前不拆除绘图UI；没有修改时直接结束编辑。系统强退不承诺恢复未保存笔画。原PNG/MP4导出不叠图形，H不改变原导出结果。

## 模块与永久数据

[drawing-model.js](../../../plugin/drawing-model.js)负责数据校验/几何/有界历史，[drawing-ui.js](../../../plugin/drawing-ui.js)负责SVG/工具/输入/未保存选择；[drawing-session.cjs](../../../plugin/drawing-session.cjs)负责编辑态、原生条目关联和合并列表；[drawing-store.cjs](../../../plugin/drawing-store.cjs)只读写本地永久数据。app注入存储和交接，Session仍独占源/播放器代次，eagle适配层仍独占SDK。统一列表保留不可变引用，不因每帧或显隐切换重建标注列表。四个运行文件已加入打包白名单；没有重建任何发行包，也未准备新的历史自动测量入口。

数据首次保存时才创建plugin/annotation-data，开发版对应同名目录；清缓存/开发临时清理不会访问它，Git和发行包排除。owner为eva-drawing-store-v1；按规范库路径+itemID隔离文档，每条再绑定源SHA/真实源帧，改名同源能继续读取，替换内容保留旧记录但不套用。升级/搬迁插件必须保全该目录；更改资料库实际路径后的关联迁移仍须单独处理，不能猜测另一资料库的数据属于当前素材。

文档≤1MiB、≤256条记录，单条≤128对象/单笔≤2048点/文字≤4096字；编辑对象≤256KiB，历史最多32步且总数据限制4MiB。达到限制明确报错。每视频仅保留最新两份完整修订，含显隐偏好的提交都走同一个严格读取/验证/写入协议；未知字段/文件/损坏不当作空数据覆盖。完整临时文件fsync后，以同目录排他硬链接提交新修订，不留长期写锁；竞争者不能覆盖胜者，已提交遗留链接只在文件身份相同时恢复。需要支持硬链接的可写文件系统，尚未验证exFAT/网络盘；不支持时保留既有数据并报告保存失败。没有修改memory-settings格式。
