# E-21 点阵时间轴试版记录

2026-10-23。正式代码试版，视觉效果待用户确认。

## 实现

工具固定左侧，记录恢复右侧，拖宽手柄回到记录左边；设置在左侧入口旁，不覆盖记录。轮盘reset保存可视中心到fixed窗口坐标，退场期间不再跟随screen布局移动，新手势恢复相对定位。

frame-dots.js使用Session只读源帧索引，以真实PTS映射每个点。普通点半径1.4px，标注点7px，相邻标注中心距离不超过半径和加7px时以曲线连接，统一实色填充消除重叠接缝。原命中按钮、片段头尾、当前帧游标保留；不显示时间数字。单Canvas，DPR上限2，静态内容仅随源帧、标注、可见范围或尺寸变化绘制；播放只移动原有游标。高密度帧在全段视图下可能视觉合并，并不抽掉真实源帧。
