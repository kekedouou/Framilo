# UI-02：扁平视觉静态对照

2026-10-23用户否定UI-01的玻璃存在感与记录区组织，授权重新规划并以HTML/CSS制作至少三款静态稿，用浏览器截图比较；补充顶栏最小化、最大化／还原与关闭。无需本轮制作可操作产品，不修改正式播放器或追认旧样稿体验通过。

## 范围与已定边界

- 源码仅`prototypes/video-first/design-round-02/`，截图同目录`shots/`。使用同一组代码绘制的SVG特效帧和一致示例文字，无AI图片、真实素材读取、素材库连接、保存或导出操作。
- 扁平、不用玻璃模糊／体积阴影／大圆角；色彩点缀限标识、选中、进度和片段。三稿分别为深炭暖金一体轨、青绿切角工作台、钴蓝浮页，差异包含顶栏、轨道和面板连接方式，不仅换色。这些是待选设计，不是新正式品牌。
- 图3按按钮窄轨在记录栏左侧、记录单列纵排理解。每源帧一张全宽缩略图，仅选中后在顶部显示简短内容；不保留双列网格或空白预留区。较早同帧多条不合并原数据的边界保持。
- 分别画观看、记录、统一标注、设置四种静态状态。记录让位、关闭恢复的既有语义保留；标注文字在下方浮动，不变暗、不移动视频；设置与记录互斥是本轮为避免重叠提出的设计假设，尚未写进正式交互。设置暂停、编辑保存／未知结果保护、片段规则、R/P精度与资源标准均沿用旧要求；静态图不能验收这些行为。
- 默认观看居中、完整画幅，底部细时间轴无时间／帧数字；缓存条默认关，设置保留开关；无播放／调速按钮、导出入口、常驻侧栏。触边发现仍以右缘提示表达，静态图不证明发现率。
- 顶栏展示素材名和窗口控件，不添加传统菜单。窗口控件只是设计，不能把浏览器截图说成Eagle原生窗控集成。

## 先审查再制作

共同采用Microsoft YaHei UI／Segoe UI的本机字体、统一线性SVG图标。视频特效色是内容，界面标志色只占极小面积；不为求特色加大面积色块、网页宣传标题或装饰框。三稿以同场景、同尺寸、同状态比较。

本轮只读图3；编号1～4按纵向记录理解，不假定它定义了新的数据分组。面板逻辑先用状态图说明；截图无可操作代码，不以新增状态机重写播放器。
