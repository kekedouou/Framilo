# E-39 可读监测、固定测试与代理帧条

2026-10-27：用户要求重做E38面板与报告，明确体验观察不能作为优化对照，并追加设置内独立代理帧条。关联R-02/03/06/08、P-01～04。本轮继续不改播放/编码/缓存策略、不提交Git、不接受性能基准。

## 实施边界

- 实时面板用一句话解释当前等待和低清替代，展示真实可测的取画面、还原画面、等待提交等时间；未知阶段不猜原因。工程明细保留在原始证据，不展示给普通用户。
- 固定测试先锁定源身份、预览质量、RAM、后端、环境和操作协议，固定准备流程与三轮拖动/跳转。体验记录、旧非固定测试和新固定测试分开；缓存起始条件不合格时拒绝用于优化结论。停止、切换视频/设置和失败闭环保留。
- 报告按同条件测试历史展示等待/停顿变化，另有跨视频稳定性矩阵和独立导出图。未测项留空；无门槛不显示验收通过。旧原始报告/hash保全，以新视图重绘已有证据。
- 代理帧条独立开关，默认关闭；仅显示已发布可读取的代理分段，区别于RAM缓存绿条。范围来自真实分段，跟随片段缩放，不推断顺序完成百分比。

## 视觉计划与审查

延续黑底和淡蓝操作：黑#000000、面板#111619、文字#e4ebef、次文#91a0aa、蓝#9fc9e4、等待橙#d5a36c。现有Segoe UI/微软雅黑。面板上方一个现象说明，下方横向时间条；比较报告以成组横条和同轴历史线为主，直接写“更短/更长”，不将代码、请求ID、JSON或统计术语放进用户界面。参考图的横条帮助说明耗时，但不照抄不存在的“传输”独立测量。克制直角与原播放器一致；小屏可滚动、键盘可达、尊重减少动态效果。
