# E-12交付：画面手势与方向轮盘

2026-10-22，接续[E-11](../E11/report.md)，同一plugin入口。**实现与本地检查完成，真实Eagle手感待验**；[计划](plan.md)范围不扩成完整UI设计。

左右按住画面控制当前显示范围的进度，松手走原准确定位；循环展开范围同样适用。向上短甩加一个已设倍速步长，继续移动按位移连续提高，向下相反，停手不自动变化。Shift增强2倍、Ctrl减半，同时按为正常值，改变修饰键只影响后续移动。范围仍0.1×～4×，Player只将步长算术扩为千分位，保证0.25步长减半后与X/C衔接不丢精度；解码/缓存与资源限额不改。

越过约6屏幕像素、优势方向确定后锁定横向或纵向直到松手；原地约420ms长按显示方向盘，**只有左右进度/上下倍速提示，没有N/D/导出/循环等新增方向命令**。错误提案已撤回。移动有淡箭头，调速左上角短暂低干扰提示，显隐/缩放动画不阻塞输入，支持系统减少动画设置。

screen-gestures是纯识别模型，screen-gesture-ui负责指针/Window时钟、每渲染帧合并定位及显示，ui调用原Session。绘图、输入、选区、导出、设置优先；失焦、按键丢失、取消、切源和销毁清理状态。仅画面操作取得焦点，不全局解除输入框快捷键保护。
