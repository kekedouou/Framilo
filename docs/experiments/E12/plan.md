# E-12：画面手势与常用操作轮盘

2026-10-22用户批准开发，接续E-11，同一plugin入口。引用R-03/08、P-01/04，沿用R/L、逐帧/导出和设置语义；整体UI和原长期性能专项仍在后续。

## 批准行为与待协定点

左右按住拖动画面控制进度；向上甩加一个倍速步长，继续向上移动则按步长连续提高，向下相反；停手不继续变化，速度0.1×～4×。Shift为2倍进度灵敏度/倍速步长，Ctrl为一半，两键同时按下按正常值。倍率随下一段移动生效、不跳当前位置。

一次按下只识别一种操作，确定方向后锁定直到松手；原地长按进入轮盘，移动显示淡方向提示，不能又调进度/速度。绘图/文本/导出/设置/选区中的交互优先，不抢占；指针取消、失焦、松键及切视频释放状态，不遗留拖动或定时器。水平定位沿用时间轴的末次目标优先和松手准确定位，保持已确认的暂停语义。

用户澄清轮盘仍表示既定左右进度/上下倍速，不另分配文字、圈画、导出或循环动作；长按出现同一手势方向盘，移动后仍按同一方向锁定规则处理。松手/失焦/Esc收回，不附加执行其它命令。左上角低干扰倍速提示和轻量显隐/方向动画不改变视频布局、不让动画阻塞输入。具体识别阈值和长按时机按小型模型/原生DOM验证，集中真实体验后可调整，不新增依赖。

## 模块与验证

独立screen-gestures纯状态机与screen-gesture-ui输入/提示层，ui只连接既有Session/动作。不得把手势识别混进Player解码缓存。读取当前显示时间范围，水平缩放与L循环展开一致。

覆盖横/纵锁定、甩动/连续移动与停手、Shift/Ctrl切换、边界、轮盘长按/选择/取消、失焦/指针丢失、编辑互斥、快速输入合并、关闭重开。默认纯模型、Node16兼容和真实Chrome DOM验证；不恢复专门一小时测量，不据此称Eagle性能已过。交付同一入口集中体验本包，轮盘设计不提前扩大为完整UI重设计。
