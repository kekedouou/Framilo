# E-08：时间轴与操作完善

## 批准范围与交付

2026-10-19用户批准主线功能包2实施：常驻自适应秒刻度，L联动循环与片段展开，长按R临时恢复整段调整，以及现有快捷键的清楚提示。仅维护plugin正式入口“视频分析”，不新增测试插件或修改冻结Beta。关联R-02/03/05/08、P-01/02/04；属于批准的演进行为，不把代码/模型通过写成完整R/P或长期性能通过。

- TL-01：整段视图随宽度调整秒刻度密度，短片段展开时允许小数秒；文字避免重叠，始终使用原视频绝对时间，不从片段起点重新记零。刻度、缓存绿条、范围/端点、实际画面时间提示和标注共享同一可见时间范围。
- TL-02：有效范围启用循环时展开片段，关闭循环恢复整段、保留淡显范围；无范围按L仍只提示。R短按的选择/确认/清除语义不变，清除后关闭循环并恢复整段。识别为长按R后暂停、保留端点并临时显示整段；拖动期间不跟着端点缩放。松R且修改有效时确认、展开新范围并循环；未修改/不足两端或Esc取消时恢复原范围及对应显示并保持暂停。原有输入法、重复键、文字输入保护保留。
- TL-03：沿用空格、R/L、【/】、滚轮、Enter/Shift+Enter，补使用提示；不擅定新增键位。选择/确认/取消、刻度和放大状态使用固定空间或浮层，不让视频画面随模式变化缩小。

开发中补问已获用户确认：从侧栏点击循环范围外的标注时，同时关闭循环并恢复整段，保留头尾，之后按L可重新开启。按定位所得真实源帧是否落在范围内判断，所选结束帧的有效持续时间仍算片段内；不自动修改端点、不临时保留一个与当前位置不符的放大视图。

本轮不做任意倍率/平移、自定义改键、连续缩略图或新增时长支持；通用侧栏焦点行为、悬浮设置留功能包3。时间轴放大不是图像放大，不重新准备视频或调整RAM、磁盘缓存、音视频/颜色/导出范围。

## 实施边界与风险

UI纯映射模块统一处理可见起止、时间与横向坐标、刻度及区间裁切；Session/Player仍管理真实源帧、播放及确认范围，UI不访问Eagle/文件。展开包含结束帧的可见时间，不能把一个画格的零宽位置当成循环总时长；片段两侧留少量显示余地，短范围也不得除零或伪造固定FPS。正式范围/磁盘数据不为显示缩放而改写。

视图仅在范围/循环/编辑状态或尺寸变化时更新，固定一次拖动的时间映射，防止确认、临时整段、窗口缩放或异步状态把同一鼠标位置解释成另一时间。绿条仅裁切现有真实覆盖；区外标注不挤在边缘，侧栏标注仍可访问。模型/宿主装载需覆盖Eagle CommonJS存在但require根在宿主的情况，新增页面脚本按依赖顺序加载。
