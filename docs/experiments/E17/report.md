# E-17：切换视频后画面拖动修复记录

2026-10-22，基线44d3a04，范围与验证见[计划](plan.md)。局部修复与适用本地检查完成；真实Eagle体验未验证。

## 原因与修复

倍速提示用hintEpoch记住所属视频。旧实现只隐藏提示，没有在重置/超时后清除此编号。切源后update反复发现提示属于旧视频，每次调用reset；新水平拖动第一次定位触发Session/UI刷新，随即被取消，于是每次只前进一点。再次调速令提示编号变为当前视频，解释了用户反馈的恢复现象。此前“切源后提示已隐藏”的检查只检查外观，遗漏了后续持续拖动。

先扩展回归并保留旧实现失败：控制器在第一次定位刷新后丢失活动手势；Chrome真实UI同样在第二次移动未提交进度。后者已完成30个检查后失败，无页面异常。两份原始输出留在01-controller-before/02-browser-before，未用实现修复覆盖失败证据。

screen-gesture-ui新增统一hideHint：同时清理定时器、所属视频编号与提示显示状态，用于超时、新手势开始、reset及destroy。保留活动手势自身的切源检查、旧排队定位取消、指针捕获/松开及最终准确定位；不改播放器供帧策略、媒体缓存、设置或标注格式。
