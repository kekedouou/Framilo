# E-33 长视频与有界按需准备

2026-10-24用户批准开始开发：取消固定30秒入口限制，先显示当前位置，按方向准备附近画面，跳转取消过时任务，循环优先，RAM/磁盘有界，未准备位置可短暂等待；先比较分段JPEG与直接解码，再决定底层。引用R-01/02/03/04/05/07/08、P-01/02/03/04。旧R-07的30秒产品目标由本轮方向替代，代码限制只有在接入关卡通过后才移除；不把当前版本写成已支持长视频。

## 顺序与技术关卡

1. 有界读取实验：相同合成MP4对照整片JPEG、短段JPEG、短段原始帧管道。检查首帧/完成时间、输出字节、源PTS和画面校验、跳转、取消。原始帧管道不是mrv2原生嵌入解码器，不得将进程启动开销归因于mrv2。
2. 定案与模块实施：媒体负责受取消约束的读取，cache负责临时/持久分段及预算/身份，frame-index负责真实呈现顺序；session只调度，player按已知源帧请求。全片哈希、完整索引、完整PCM目前阻塞就绪，须逐项处理，不能以平均帧率伪造索引，不能降低源变化保护。
3. 正式接入：准确定位、音频分段、循环边界、过时结果隔离、可取消等待、旧缓存兼容、关闭重开恢复全部通过后，才解除30秒限制。默认短片行为不得回退。

## 授权与资源

不用真实素材库，不安装依赖，不自动加载Eagle，不修改原视频/标注/现有缓存。使用已存在FFmpeg/ffprobe。新实验代码仅在prototypes/long-video，正式插件不得引用实验目录；验证脚本显式运行，默认检查只运行无媒体模型。

本轮合成现场仅prototypes/long-video/scratch/run-随机ID，最大128MiB，最多三轮、每轮最长180秒、单子进程最长30秒、每轮同时最多一个媒体子进程。输出管道流式计数/校验，不落整片原始帧。合成源为45秒低分辨率CFR与VFR/B帧/偏移样本，先验证机制，不代表4K/60fps性能。证据verification-runs/e33-long-video最多16文件、单份256KiB、总4MiB，不覆盖失败记录。清理前记录文件身份/哈希/大小，仅删除本轮创建且身份一致的文件，目录必须在已验证现场内。
