# Motionote Logo：第一轮五款方向

[对照图](contact-sheet.png) · [矢量对照图](contact-sheet.svg) · [可缩放浏览页](index.html) · [第三阶段计划](../../experiments/E53/plan.md)

先选构形，再细化最终字标、颜色和图标光学校正。没有替换plugin/logo.png，也没有改插件ID或安装包。

当前状态：用户随后决定名称与Logo一并重做，先选英文名称；此前A「折帧M」的偏好保留为历史参考，不再作为下一版定稿方向。本目录保留第一轮原稿，未替换正式品牌。名称候选见[E53计划](../../experiments/E53/plan.md)，公开资料初筛及局限见[E53记录](../../experiments/E53/report.md)。

| 方向 | 核心 | 取舍 | 矢量文件 |
| --- | --- | --- | --- |
| A 折帧 M / Fold | 用字母M表现连续画面的折叠 | 小尺寸轮廓最稳；字母M本身较常见，最终可进一步定制折角 | [A](a-fold.svg) |
| B 留下注记 / Margin | 画面取景框与边缘书签 | 最直接体现“观察＋标注”；16px书签较细，需要最终像素级校正 | [B](b-margin.svg) |
| C 运动轨迹 / Trace | 连续曲线写出m | 柔和、有人手观察感；与现有硬朗界面有意形成差别 | [C](c-trace.svg) |
| D 画面引语 / Quote | 把视频当作可以引用、留下批注的内容 | 符号鲜明、单色稳定；首次看到不一定联想到播放器 | [D](d-quote.svg) |
| E 捕捉一刻 / Moment | 播放环上的一个注记点 | 播放含义清晰；较接近常见媒体图标，专属性弱一些 | [E](e-moment.svg) |

建议优先比较A和B：A更适合建立品牌记忆，B更准确表达本产品的工作方式。保持五种独立构形，不只更换颜色。

设计基准：黑#080a0c、近白#eef1f4、淡蓝#9bc4df、深蓝灰#739bb8、展板灰#e7e9ec。黑白两用，直线与必要曲线，不加投影、玻璃、3D或依赖渐变辨识。字标先用本机Segoe UI（B网页用Bahnschrift作方向参考），不捆绑字体；最终字标尚未转曲/定稿。对照图统一用Segoe UI比较构形。

HTML展示暗底组合和亮底16/24/32px单色图标。PNG由矢量展板导出，不冒充浏览器截图；原SVG可任意缩放。初稿独立绘制；已做名称公开资料初筛，未完成目标市场商标权利检索，不宣称可注册、可独占或无侵权风险。
