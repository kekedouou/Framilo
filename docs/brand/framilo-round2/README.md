# Framilo：重新探索六个方向

用户否定全部E变体后重新探索，并从本轮选定A「流线」。当前[定稿与运行图标](../framilo-final/README.md)已采用该方向，本目录保留六款原始比较稿。

## 方案与取舍

| 方案 | 设计 | 待判断的取舍 |
| --- | --- | --- |
| A 流线 | 开放、弯曲的F | 小尺寸清晰，但字母含义较直接 |
| B 相连 | 两个相接的开放环 | 体现关联，亦容易让人想到链接 |
| C 回响 | 两道曲线与端点 | 更轻柔，也可能被理解为声音符号 |
| D 落笔 | 墨滴与方形留白 | 强调记录，视频含义较弱 |
| E 留白 | 实心轮廓中的负形F | 适合应用图标，但仍是字母方向；与旧E连续帧无关 |
| F 连字 | 手绘Framilo字标，配小写f | 更有亲和力，字距和曲线需要选定后进一步校正 |

## 设计与检查

计划：放弃帧片/折角，在轮廓、曲线和字标结构上拉开差异；黑白和淡蓝保持一致。三列两行、左对齐说明、统一大小的主标识与16/24/32px单色样本。另提供白底单色板，排除背景与颜色对选择的干扰。前五款用本机Segoe UI字标；F全部由矢量路径构造，没有下载或打包字体。

批判性检查：A/E最易识别字母，但不应因此直接定稿；B/C有其它常见符号联想；D更偏记录；F更柔和，但不是最终光学校正字标。小尺寸细节仍需用户选定后专项处理。未进行商标或图形相似性清查。

已目视检查1536×1152对照图：六款、字标、小尺寸与说明均完整，没有截断。Ego在1440/800/390px检查六卡及文档无横向溢出；单色板小屏可局部横向滚动。原始回执在verification-runs/e53/framilo-new-layout.json。本轮仅品牌设计，不证明播放器性能或真实Eagle体验。
