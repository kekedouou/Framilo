# Framilo：六款 Logo 方向

用户已确定名称Framilo。本轮只做新品牌设计提案，不替换正式插件图标、不改变插件ID或存储目录。名称选择不代表商标可用性已核查通过。

历史选择：用户曾偏好E「连续帧」，随后否定全部E变体并放弃该方向。当前见[六款新方向](../framilo-round2/README.md)。本目录保持首轮原构形不变。

建议优先比较A、D、E，但没有默认选中项。先确定构形，下一轮才做最终字标、图标光学尺寸和正式应用组合；旧Motionote A稿仅作历史参考。

设计计划：统一黑#080b0e、白#f2f5f7、淡蓝#98bdd8、深墨#171c22、展板灰#f1f2f3；所有方案使用同一背景和字标尺度，色彩不是方案差异。Bahnschrift/Segoe UI本机字体作为几何字标参考，不捆绑字体、不宣称最终字标定稿。三列两行等权展板，大图标居中，说明左对齐；小屏变两列/单列。

自审：避免六次变色的同一F、播放三角套圆、玻璃/渐变装饰；构形分别落到字母、折页、轨迹、注点、帧序列与观察轮廓。F初稿过于像六边形零件，已改为曲线眼形。A/B偏稳妥、C/E偏抽象，取舍如上，不宣称原创性法律结论。

交付：SVG独立可编辑、透明背景；PNG为矢量展板经浏览器Canvas导出，不是HTML截图。各方案包含16/24/32px单色样本及深浅底图标。浏览页无网络请求、无需服务，直接打开index.html；如浏览页不可用可打开PNG或SVG展板。它只供视觉选择，不是播放器交互/真实Eagle验收。运行 `node docs/brand/framilo-round1/build.mjs` 可重建SVG及HTML（不生成PNG）；正式源文件本目录，渲染检查回执在verification-runs/e53，沿用E53品牌≤8MiB边界。
