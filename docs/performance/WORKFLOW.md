# 即时性能监测与开发验证

E45起按用户决定废除旧体验记录、固定标准测试、待分析槽和report.html架构。旧E38～E44文档保存当时结论，运行入口、安装清单和当前检查不再调用对应报告程序。旧文件清理被工具策略拒绝，尚未删除，清单见E45记录。

## 用户界面

设置→性能监测仅打开独立即时窗口。显示当前等待、最近完成请求P95、RAM命中及排队/读取/解码转换/传输/绘制阶段；尚未得到画面时仍显示阶段与累计等待。监测仅保留最近200个请求和1000个事件，滚动淘汰旧观察，不写磁盘记录。

四项资源：插件相关进程工作集（RSS）、当前视频受管缓存和解码/绘制预留、插件全部视频缓存磁盘、本视频各画质缓存磁盘。工作集与受管预留不是可相减的同口径值；共享GPU、其它Eagle进程及原素材不包含其中。读不到时显示横杠。监测关闭即停止采样。

E50改为异步逐文件磁盘校准，关窗同时取消在途扫描/自有采样子进程，源切换不发布旧源的当前占用。相同事件快照不反复汇总，但等待时间继续更新。总磁盘悬停显示代理（含临时）、其中临时/待回收、JPEG、其它缓存/回执；分类是采样，临时为代理子集。性能面板本身不得成为播放阻塞来源，检查需保留同目录旧/新计时及统计字节一致性，不用清空回执缩小问题。

原生寻帧与解码等待包含读取、GOP前滚、解码和管道返回，未收到进程结果前不能编造纯GPU/纯磁盘分项。绘制提交不是物理屏幕刷新。显示旧帧不算新目标完成，准确标注保护不因等待画面保留而解除。

每轮只运行受影响的回归和必要实际媒体检查，不建立新的用户报告架构。临时测量保留源身份、配置、测量边界、代码/二进制身份与结果；性能前后同源同条件，首个冷跳、连续播放、RAM复访分开。默认检查不生成媒体、不操作素材库；涉及宿主验证时如实区分实际Eagle、独立浏览器与模型。
