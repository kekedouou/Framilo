# Framilo

**选一段视频，慢下来，看清每一帧。**

Framilo 是 Eagle 中的视频参考与标注播放器，为特效、动画与视频创作者提供逐帧观察、关键画面标注和参考记录回看。

[开始使用](#开始使用) · [常用操作](#常用操作) · [性能与限制](#性能与限制) · [你的数据](#你的数据) · [开发与许可](#开发与许可)

## 看清细节

后台生成预览代理，支持拖动定位、逐帧查看、慢放与片段循环。点击画面或按空格播放、暂停，滚轮逐帧观察；选择片段后，可以反复查看一段动作的变化。

## 把发现记在画面上

按 N 添加标注，用文字说明重点，或用手写、箭头、矩形、椭圆和画面文字圈出细节。文字与圈画一起保存，便于在回看时理解当时的观察。

## 快速找到想看的位置

通过记录缩略图辨认已标记的画面，点击返回对应位置；也可以拖动画面或时间轴定位。

快速拖动时会跳过部分中间帧，松手后准确定位。目标准确帧尚未就绪时，可能暂时保留上一张画面，此时不能基于旧画面保存新标注。

## 开始使用

需要 **Windows x64、Eagle 4.0 Build 22 或更高版本**，无需升级到最新版本。使用时不用另装 Node.js 或 Rust。

1. 在 Eagle 插件中心安装 **FFmpeg 依赖插件**。
2. 通过 Eagle 安装 Framilo；使用 `.eagleplugin` 文件时，通过 Eagle 打开并安装。
3. 在 Eagle 中选中一个本地视频，再打开 Framilo。
4. 开始播放、逐帧观察或添加标注，按 B 查看记录。

支持 **MP4/M4V、MOV、MKV、WebM**，实际兼容性取决于视频编码。GitHub 源码 ZIP 不是 `.eagleplugin` 安装包。

若提示缺少接口，请确认 Eagle 版本符合要求，并重启 Eagle 后重新打开 Framilo。

## 常用操作

| 操作 | 用途 |
| --- | --- |
| 点击画面 / 空格 | 播放、暂停 |
| 画面或时间轴内滚轮、`[` / `]` | 前后逐帧查看；滚轮步长可在设置中调整 |
| 左键左右拖动画面 / 拖动时间轴 | 定位画面 |
| 左键上下拖动画面 | 调整倍速 |
| Z / X / C | 恢复正常速度 / 减速 / 加速 |
| N | 进入标注 |
| 短按 R | 选择 / 确认片段，已有片段时清除 |
| L | 开启 / 关闭已选片段循环 |
| B | 展开 / 收起记录 |
| O | 打开设置 |
| Enter / Shift + Enter | 保存标注 / 文字换行 |
| Esc | 取消或退出当前操作，有未保存内容时会提示确认 |
| F11 | 全屏切换 |

画面手势适用于观看状态；输入文字时保留正常的文字编辑操作。绘图中可用 Ctrl + Z 撤销，Delete 删除选中对象。

**右键轮盘**：在画面上按住右键，移向选项后松开执行；也可直接向对应方向拖动后松开。回到中心松开或按 Esc 取消。

观看时，轮盘提供标注、记录、片段选择和循环；圈画时切换为工具类型、颜色、撤销和橡皮。标注完成后，可在画面上短按右键保存退出；输入框内保留系统右键菜单。

## 性能与限制

解码器、电脑配置和画质都会影响流畅度，高画质下无法保证完全流畅。建议优先选择 **1080p 或 2K（1440p）**。较大或较长的视频需要更多准备时间，更高分辨率、帧率或码率也可能增加卡顿。

**个人体验参考**：开发者在配备 RTX 3060 的电脑上使用硬件解码，原视频为 2K、插件画质设为 2K／1440p、时长在 10 分钟以内时，播放通常较流畅。这不是最低配置或通用性能保证；10 分钟不是支持时长上限，也不代表启动、代理准备或逐帧拖动的耗时保证。

代理文件可能占用较多磁盘空间，尤其是高分辨率或较长的视频。预计本窗口临时媒体累计超过 **1 GB** 时，会询问是否继续生成；选择不继续时仍可播放原片。

已知问题：Windows 中文输入法候选框偶尔残留，尚未修复。

## 你的数据

原视频保持不变。主动保存、编辑或删除文字标注会更新 Eagle 对应素材。

- **圈画与画面文字**：保存在插件目录的 `annotation-data/`，不随 Eagle 素材库同步或迁移，暂无内置导入／导出功能。
- **偏好设置**：保存在插件目录的 `memory-settings.json`。
- **临时媒体**：位于插件目录的 `cache/`，正常关闭时清理本窗口生成的内容，重新打开时再准备。异常退出后的残留需后续确认安全后再清理。

卸载正式安装版会随安装目录删除圈画和偏好，请提前备份；不能只备份程序或只备份 Eagle 素材库。主动删除某帧最后一条文字标注时，也会清除该帧圈画。完整保存、清理与备份规则见[数据说明](docs/releases/framilo-package-readme.md#数据说明)。
