# Framilo

**选一段视频，慢下来，看清每一帧。**

Framilo 是 Eagle 中的视频参考与标注播放器。逐帧观察动作，循环查看片段，把文字和圈画留在对应画面上。

[GitHub主页](https://github.com/kekedouou/Framilo) · [开始使用](#开始使用) · [常用操作](#常用操作) · [你的数据](#你的数据) · [能力与限制](docs/releases/motionote-capabilities.md)

## 看清细节

点击画面或按空格播放、暂停，滚轮逐帧查看。需要反复观察一段动作时，设置片段起点和终点，开启循环；也可以放慢播放速度。

## 把发现记在画面上

按 N 添加标注，用文字说明重点，或在画面上圈出位置。文字与圈画一起保存，通过右侧记录回到对应画面。正在输入文字时，空格保留正常输入。

## 快速找到想看的位置

拖动画面或时间轴定位。快速拖动时会跳过部分中间帧，松手后准确定位；画面还在准备时，会保留上一张画面，暂时不能保存新标注。

较大的视频需要准备时间，未缓存的4K画面不保证立即显示。具体格式、画质和资源限制见[能力说明](docs/releases/motionote-capabilities.md)。

## 开始使用

需要 Windows x64、Eagle 4.0 Build 22+ 和 Eagle 的 FFmpeg 模块；使用时不用另装 Node.js 或 Rust。缺少 FFmpeg 时，可在 Eagle 插件中心安装。

不支持 Build 22 之前的 Eagle。版本过低会提示升级；若提示缺少接口，请确认版本符合要求并重启 Eagle 后重新打开 Framilo。

当前版本为 1.0.0，处于首轮上架前整体审查，尚未公开发行，也不代表最终以此版本上架。已在 Eagle 注册本仓库插件的用户：

1. 在 Eagle 选中一个本地视频。
2. 打开 Framilo，等待画面准备完成。
3. 开始播放、逐帧查看或添加标注。

后续更新直接修改仓库中的 plugin 文件夹，关闭播放器后重新打开即可，不用每次解压新包或搬动目录。首次载入、审查包、版本恢复和数据保护见[使用说明](docs/releases/framilo-private.md)。Windows 中文输入法候选框跨帧残留仍未修复，本阶段暂缓，详见[问题登记](docs/acceptance.md#问题登记)。

## 常用操作

| 操作 | 用途 |
| --- | --- |
| 点击画面 / 空格 | 播放、暂停 |
| 滚轮 | 逐帧查看 |
| 拖动画面 / 时间轴 | 定位画面 |
| N | 标注 |
| R | 片段 |
| B | 记录 |
| O | 设置 |
| F11 | 全屏切换 |

## 你的数据

原视频保持不变。主动保存、编辑、删除文字标注会更新 Eagle 对应素材；圈画保存在插件的 annotation-data 文件夹，本机偏好保存在 memory-settings.json。备份时需要同时考虑 Eagle 标注和插件中的圈画，不能只备份程序。

正常关闭后，播放器清理本窗口生成的临时媒体，重新打开时再准备；缓存清理不删除原视频、标注或偏好。预计临时媒体累计超过1 GB时，会先询问是否继续。圈画的素材删除、卸载和恢复规则见[数据说明](docs/product.md#圈画数据归属与删除)。

遇到问题时，记录最后一步操作、出现的现象和使用版本即可，不必上传原片或整个素材库。
