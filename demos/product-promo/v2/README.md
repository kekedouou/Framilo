# 功能演示 v2：RIOT 与原标注

2026-10-26用户要求：参考SimuSub的清晰标题与操作节奏，使用灰蓝背景，保留播放器原生动效；以指定RIOT素材展示无标注区域的操作，再回到第一段光束展示已有标注。不限制时长。

## 画面与编排

1920×1080、30fps，计划108秒，无配音/配乐。灰蓝底#63717c、背景亮部#7c8994、深部#56636e，白色标题#f3f5f6与浅蓝提示；56px中文标题、24px辅助说明。使用现有正式界面，外部演示画框补章节轻扫、标题进场与设置区轻度放大。没有禁用正式CSS动画，原记录栏、轮盘、设置菜单动画由浏览器原生Animation时间轴按视频帧推进。

| 时间 | 操作 |
| --- | --- |
| 0–12秒 | 素材卡片选择、载入过渡、无标注片段播放 |
| 12–23秒 | 拖动回看、X快捷键降低至0.5倍、暂停到未标注帧 |
| 23–38秒 | 呼出类型轮盘、选箭头、绘制指向拖尾的箭头、输入文字并在隔离会话保存 |
| 38–63秒 | 回到4.05秒起的第一段光束，以0.1倍播放，使用用户原有0.05秒淡化设置 |
| 63–88秒 | 记录栏原生展开，拉宽再收窄，按时间顺序点击7条原记录 |
| 88–108秒 | 设置主菜单、高级、内存/倍速下级、画质1080p与应用状态 |

## 数据与实现边界

原视频只读本机播放，原Eagle文字标注与插件revision14圈画快照只读复制到被忽略的private-data.json。源SHA与全部圈画sourceSha256核对一致；config.local.json只在本机保存具体路径。视频、原标注、快照与日志不上传、不入Git，未修改素材库或现有偏好。

index.html负责外围画框与剪辑节奏，fixture.js加载真实RIOT画面、原圈画及正式UI，提供隔离的模拟Session。绘制箭头和文字输入走正式DOM事件，保存只停留在内存；记录跳转与设置应用由模拟Session响应。素材选择卡片、加载时长、画质准备过程是演示编排，不是Eagle原生选中窗口或真实缓存性能实录；记录栏宽度通过正式键盘调整事件驱动，并以拖动光标演示同一宽度变化。画质应用切换真实Canvas输出尺寸，但不运行正式后台缓存制作。

原生动画的绘制时间以成片时间驱动，源码与动画定义保持；渲染期间加载的只是本地页面，没有加载/安装Eagle插件。E36开发继续暂停，E37真实宿主验收不变。

## 复现与记录

先在本机提供config.local.json和private-data.json及thumb-0～6.jpg/poster.jpg，再运行node demos/product-promo/v2/render.cjs。--preview导出关键帧；--short限制前37秒供圈画定位。使用已有Chrome与FFmpeg。输出为functional-demo-v2.mp4，不覆盖v1。

预算：视频≤256MiB，参考/检查记录≤32MiB，自有浏览器scratch沿既有清理器≤64MiB。临时目录退出后逐文件核对身份与SHA再清理，回执在渲染日志；原媒体与插件缓存不动。

第一轮预览发现每帧强制resize提前结束画笔，保存对象数为0；移除多余resize后恢复箭头，又补齐模拟Session.touchDrawing。两轮预览记录保留。最终渲染要求页面错误为空、箭头对象1个且有文字、7次记录跳转、1080p应用事件，否则失败。
