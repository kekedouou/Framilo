原视频、metadata、revision14圈画及私人缩略图继续只读复用v2本机资产。原生UI/CSS、轮盘事件、绘图、片段选择与菜单动画保持；定时器及动画依旧由视频时钟推进。画面解码/播放和保存由独立模拟Session提供，不代表真实Eagle或缓存性能验收。
