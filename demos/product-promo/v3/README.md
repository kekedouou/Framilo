# 功能演示 v3：轮盘、局部特写与片段循环

2026-10-26用户要求收紧节奏、略调暗背景，移除玻璃反光转场、自创加载页和角落提示；尽量通过轮盘操作，补上片段循环。追加要求：标题不常驻顶部，产品画面随操作改变大小、位置与裁切。

## 编排

成片56秒，1920×1080、60fps，无音轨。保留v1/v2，输出functional-demo-v3.mp4。背景亮部#586672、中部#4a5863、深部#43505b；章节标题只短暂出现，左右构图与顶部构图交替。随后产品画面展开，轮盘、时间轴、文字输入和设置采用局部特写；以平滑推近/拉远连接，不加反光扫屏。

| 时间 | 展示 |
| --- | --- |
| 0–8秒 | 直接播放，左键长按手势轮盘回看、调速到0.2× |
| 8–16秒 | 右键轮盘打开标注，展开类型二级轮盘选箭头，画箭头、输入文字并在隔离内存会话保存 |
| 16–28秒 | 第一段光束以0.2×播放，显示用户原有标注淡入淡出 |

## 实现与边界

复用v2本机config.local.json、private-data.json和缩略图，不重复复制原媒体/标注。原RIOT视频、metadata及revision14圈画只读。原正式UI代码/CSS保持不变，演示Session独立；视频按源帧定位，轮盘、绘图、片段选择和设置走正式DOM事件。记录滚动使用Chrome的真实mouseWheel输入，宽度通过正式拖动处理器响应；合成指针没有硬件捕获，演示里仅将捕获调用替换为空函数。

UI定时器及performance.now由视频时间推进，原CSS Animation暂停后逐帧推进，避免420ms长按和100ms二级轮盘悬停受渲染机器速度影响。媒体解码超时保持真实时钟。模拟Session的片段边界和循环由脚本响应，不运行正式缓存/媒体后端，不是Eagle宿主性能或真实体验验收。

初次预览发现浏览器输入焦点将放大画框滚偏，导致轮盘被裁切；演示内统一focus preventScroll，并恢复外围画框滚动原点，后续预览复核。原生UI源码不为录制更改。后续按用户反馈取消常驻标题和固定画框。

## 复现、预算与验证

在仓库根运行node demos/product-promo/v3/render.cjs；--preview只生成30张关键帧与操作审计。使用本机已有Chrome/FFmpeg，完整导出3360帧；重复运行会替换同名v3输出，应先判断是否需要保留。

视频≤256MiB、检查截图/记录≤32MiB、每轮自有Chrome scratch≤64MiB。浏览器scratch按已有annotation-scratch逐文件身份/SHA核对清理，回执写渲染日志。前版保留作对照；v3最终关键帧、失败说明和必要日志在本机保留，用户媒体和私人数据不入Git、不上传。

渲染要求页面错误0、隔离保存一个箭头与完整文字、仅两次记录跳转、片段范围成立、至少两次循环回环、记录滚动超过150px、三级菜单打开。成片解码与原文件SHA复核结果在本机final-check.json。

文档影响：只更新演示导航及当前进度。正式产品、架构、路线、模块导航、冻结实验与发行包不受影响；未重跑产品历史关卡，E36仍暂停、E37宿主体验仍待验。三个原有暂存探针保留且不纳入本轮提交。
